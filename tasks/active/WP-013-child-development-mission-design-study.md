# WP-013 아동 발달 기반 원더미션 설계 연구

- 연관 목표 또는 Gate: Gate 1 카드 사용성 검증, WP-011 후보 미션 40개 작성 전 선행 연구

## 목적과 범위

만 4~9세 아동의 행동 패턴, 인지·언어·사회정서·운동 발달, 놀이와 자기조절 원리를 학습하고, 이를 원더미션과 원더팩의 질문 난이도·보호자 개입·성취 피드백·안전 기준으로 변환한다.

만 4세는 발달 경계와 접근성 검토 범위에 포함하되 현재 원더팩의 판매·검증 타깃은 기존 결정대로 보호자 동반 5~9세를 유지한다. 이 연구는 교육효과를 확정하거나 발달을 진단하지 않는다.

## 핵심 연구 질문

1. 만 4~5세, 6~7세, 8~9세는 각각 어떤 방식으로 관찰하고 비교하며 이유를 설명하는가?
2. 선택권, 이야기·상상, 규칙, 협동, 수집·분류와 도전 중 어떤 장치가 연령별 참여를 시작하고 지속시키는가?
3. 작업기억·억제·인지적 유연성의 차이를 카드의 문장 길이, 단계 수와 전환 규칙에 어떻게 반영할 것인가?
4. 정답·보상 중심이 아닌 성취감을 어떻게 만들고, 실패나 중단을 어떻게 정상적인 탐구 과정으로 표현할 것인가?
5. 보호자는 언제 기다리고, 질문하고, 힌트를 주며, 언제 안전을 위해 개입해야 하는가?
6. 탐구·창의·성취·모험 활동이 실제 야외에서 5분 안에 작동했는지 어떤 행동으로 관찰할 것인가?

## 산출물

1. `docs/wonderpacks/CHILD_DEVELOPMENT_MISSION_DESIGN_STUDY.md` 학습·설계 가이드
2. 연령대별 `관찰 가능한 행동 → 설계 원칙 → 금지 패턴` 매트릭스
3. 원더미션 카드 검수 루브릭과 보호자 개입 사다리
4. 탐구·창의·성취·모험별 예시 미션 2개씩, 총 8개
5. 전문가 검토 질문지와 5가족 인지 인터뷰·행동관찰 프로토콜
6. 출처 URL·확인일·사실/추론 구분이 있는 근거 기록
7. WP-011 후보 40개에 반영할 수정 규칙과 미해결 가설
8. 이동 중 단독 학습이 가능한 `docs/wonderpacks/CHILD_DEVELOPMENT_MISSION_DESIGN_TEXTBOOK.md`와 PDF 자습서

## 실행 순서

### 1. 근거 학습 — 2026-07-17~07-19

- 한국 2019 개정 누리과정과 초등 저학년 교육과정의 목표·놀이·자연탐구 기준을 확인한다.
- CDC 발달 이정표는 만 4~5세 행동의 참고 범위로만 사용하고 진단 기준으로 사용하지 않는다.
- NAEYC의 발달적합실제와 안내된 놀이, Harvard의 실행기능·자기조절 자료를 읽는다.
- 체계적 문헌고찰 또는 공공기관 근거가 있는 야외놀이·창의성·성취동기 자료를 보강한다.

### 2. 제품 규칙 변환 — 2026-07-20~07-21

- 자료의 문장을 그대로 요약하는 데서 끝내지 않고 카드의 문장 길이, 단계 수, 선택지, 힌트와 성공 판정으로 바꾼다.
- `4~5세 / 6~7세 / 8~9세` 가설을 만들고 현재 제품의 `5~6세 / 7~9세` 표기와 비교한다.
- 접근성·문화·언어 차이와 개인차를 반영해 한 연령에 하나의 능력을 단정하지 않는다.

### 3. 예시 미션·루브릭 제작 — 2026-07-22

- 탐구·창의·성취·모험 각 2개의 종이 미션을 만든다.
- 기존 문법 `찾기 → 비교하기 → 추론하기 → 표현하기`와 안전 원칙을 유지한다.
- 각 미션에 예상 행동, 어려움 신호, 보호자 힌트, 관찰 지표와 중단 조건을 붙인다.

### 4. 성인 전문가 검토·가족 소규모 관찰 준비 — 2026-07-23~07-24

- 유아교육·아동발달 전문가에게 물을 질문과 검토 기준을 초안으로 만든다.
- 외부 연락, 가족 모집과 개인정보 수집은 사용자 승인 전 실행하지 않는다.
- 승인 후 만 4~5세 2명, 6~7세 2명, 8~9세 1명 수준의 탐색 관찰을 진행하고 연령 간 효과를 일반화하지 않는다.

## 완료 조건

- 최소 8개의 권위·1차 근거를 사용하고, 한국 공공 교육과정 자료를 포함한다.
- 모든 변할 수 있는 출처에 URL과 2026-07-17 이후 확인일을 기록한다.
- 발달 사실, 제품 설계 추론과 아직 검증하지 않은 가설을 구분한다.
- 연령대별 설계 매트릭스, 카드 검수 루브릭, 보호자 개입 사다리와 예시 8개가 완성된다.
- WP-011 후보 미션 40개에 적용 가능한 합격·수정·탈락 기준이 있다.
- 전문가 검토와 가족 관찰 전까지는 교육효과·연령 적합성을 확정 표현하지 않는다.

## 사용자 승인 필요

- 외부 전문가에게 검토 요청 또는 인터뷰 연락
- 가족 모집 메시지 발송과 아동 행동·발화·그림 수집
- 사례비, 인쇄 또는 장소 이용 비용 집행

승인 전에는 공개 자료 조사, 질문지·동의문·관찰표와 종이 시안 초안까지만 준비한다.

## 후속 업무

연구 결과를 WP-011의 40개 후보 미션과 24장 선정 기준에 반영한다. 연령 구간이나 카드 형식을 바꾸는 근거가 나오면 제품 범위를 임의로 변경하지 않고 비교안과 시험 설계를 PM 보고에 올린다.

## 검증 방법

- 출처 URL 접근 여부, 기관·발행일·확인일과 인용 문장의 일치 여부를 교차 확인한다.
- 발달 사실, 원더핀 설계 해석과 현장 검증 전 가설을 표에서 구분한다.
- 예시 미션 8개를 루브릭으로 상호 검수하고 안전 항목 0점은 즉시 탈락시킨다.
- 성인 인지 워크스루로 문장 이해, 단계 수, 기록 가능성을 먼저 점검한다.
- 사용자 승인 후 5가족 형성평가로 첫 행동 시간, 도움 단계, 이탈·재시도와 아이 표현을 관찰한다.
