# WP-011 휴대형 야외 탐험 카드 시제품과 사용성 검증

- 상태: active
- 담당: wonderpack-developer
- PM: wonderpin-pm
- 우선순위: P0
- 목표일: 2026-08-14
- 연관 목표 또는 Gate: Gate 1 카드 사용성 검증
- 선행 업무: WP-013 아동 발달 기반 원더미션 설계 연구

## 목적과 범위

5~9세 가족이 산책길·놀이터·공원에서 별도 준비 없이 사용하는 탐험 카드 24장과 안전·사용법 카드를 설계하고, 30세트 소량 시제품으로 실제 야외 사용과 반복 사용을 검증한다.

## 산출물

1. 후보 미션 40개와 선정 기준
2. 검수된 탐험 카드 24장
3. 사용법·안전 카드, 탈착식 링 바인더형 원더핀 일기·리필 속지와 원더핀 굿즈 스티커
4. 소량 인쇄 사양과 30세트 제작 견적
5. 가족 테스트 진행안·동의·사용 기록 양식
6. 카드별 실행·완료·반복 사용 결과
7. `docs/business/CARD_VALIDATION_EXECUTION_PLAN.md`에 따른 Gate 1 판정 보고

## 실행 일정

- 2026-07-25~07-29: WP-013 핵심 산출물을 반영해 후보 40개 작성, 24장 선정, 종이 모형과 견적
- 2026-07-30: 인쇄비·모집·동의 사용자 승인 요청
- 2026-07-31~08-03: 30세트 제작과 수령 가족 15팀 확정
- 2026-08-04~08-08: 실제 야외 사용 10팀
- 2026-08-09~08-14: 다른 날 두 번째 사용 5팀과 Gate 1 판정

기존 일정은 2026-08-04 기준 지연됐다. 제품 구성은 원더미션 카드 24장 전체를 기준으로 유지한다. 먼저 `발견 탐정·비교 대결·생각 실험·상상 발명` 각 6장의 24장 포트폴리오를 설계하고, 기존 상세 카피 8장은 전체 구성과 문법을 검증하는 시드 카드로 사용한다. 24장의 장소·날씨·행동·표현 분포를 검수한 뒤 상세 카피, 종이 모형과 인쇄 승인 일정을 다시 산정한다.

## 완료 조건

- 5~6세와 7~9세 질문 난이도가 구분된다.
- 채집·위험 이동·개인정보 촬영을 요구하지 않는다.
- 시제품 수령 15팀, 실제 야외 사용 10팀을 확보한다.
- 서로 다른 날 두 번째 사용 5팀 이상을 확인한다.
- 카드 한 장 7분 이내 완료율과 보호자 개입시간을 기록한다.
- 다음 Gate의 유료 파일럿에 사용할 카드·구성·수정사항을 판정한다.

## 사용자 승인 필요

- 시제품 인쇄·구매 비용 집행
- 외부 가족 모집 메시지 발송과 개인정보 수집

비용 견적, 모집 문구와 동의 초안까지만 승인 없이 준비할 수 있다.

## 후속 업무

Gate 1 통과 시 `WP-012` 유료 파일럿으로 이동한다. 기준 미달이면 실패 카드를 수정해 5가족 미니 재시험하거나 제품 가설을 중단한다.

## 작업 기록과 현재 결과

- 2026-08-04: 제품을 `관찰 대상 8종`만으로 분류하면 모든 카드가 찾기·비교로 반복될 위험이 있다고 판단했다.
- 2026-08-04: 24장 후보 구조를 `발견 탐정·비교 대결·생각 실험·상상 발명` 4개 놀이 유형, 각 6장으로 설계하는 가설을 세웠다. 네 유형은 교육효과 분류가 아니라 아이가 경험하는 놀이 방식이다.
- 2026-08-04: 네 유형 각 2장의 시드 카드 8개에 실제 행동 카피, 기록 결과, 안전·중단 조건과 현장 가설을 먼저 작성했다.
- 2026-08-04: 사용자 검토에 따라 제품 구성은 `박스 + 원더미션 카드 24장 + 중철 수첩형 원더핀 일기 + 짧은 색연필 + 원더핀 굿즈 스티커`로 수정했다.
- 2026-08-04: 원더핀 일기는 미션 체크지가 아니라 날짜·장소·그림·아이 한마디를 모으는 반복 사용 일기로 정의했다. 매 카드마다 기록을 의무화하지 않는다.
- 2026-08-04: 굿즈 스티커는 완료 보상이나 점수표가 아니라 원더핀 일기와 개인 소지품을 꾸미는 브랜드 굿즈로 한정한다.
- 2026-08-04: 5~6세 기본 질문에는 `어디를 보고 그렇게 생각했어?` 같은 추상 문장을 단독 사용하지 않고, 가리키기와 색·크기·움직임·쓰임 등 구체적인 선택지를 먼저 제공한다. 7~9세 확장에서 관찰 단서를 스스로 설명하게 한다.
- 2026-08-04: 기존 8장 시드 카피를 `wonderpacks/briefs/WP011-24-CARD-DECK-PLAN-V0.md`의 24장 기획 안으로 전환하고 추가 16장 후보를 설계하기 시작했다.
- 2026-08-04: 4개 놀이 유형 각 6장, 총 24장의 제목·첫 행동·주요 장소·기록 방식·위험 분포를 작성했다. 우연과 기다림 의존이 큰 `무엇이 먼저 움직일까?`는 제외하고 `반쪽의 정체`로 교체했다.
- 2026-08-05: 사용자 검토에 따라 중철 일기 사양을 취소했다. 원더핀 일기는 구멍 뚫린 리필 속지를 추가·제거하고 외출에 필요한 양만 고를 수 있는 탈착식 링 바인더형으로 변경했다.
- 2026-08-05: `wonderpacks/briefs/WP011-24-CARD-DECK-PLAN-V0.md`에 최종 24장 모두의 앞면 질문, 3단계 행동, 연령별 도움, 말·움직임·일기 결과, 리필 속지 기록 예시, 안전·중단 조건과 현장 검증 가설을 작성했다.
- 2026-08-05: `wonderpacks/briefs/WP011-PRODUCTION-DESIGN-BRIEF-V0.md`에 카드·박스·링 일기·속지·색연필·스티커의 디자인 목표, 정보 위계, 접근성·안전과 인쇄 전 비교 항목을 작성했다.
- 2026-08-05: 최신 제품 구성 목업 `output/wonderpack-product-system-mockup-v2.png`와 카드·속지·스티커 디자인 보드 `output/wonderpack-card-design-system-v1.png`를 생성했다. 두 이미지는 방향 검토용이며 인쇄 원고가 아니다.
- 현재 미검증: 24장 전체의 놀이 유형·장소·날씨 균형, 원더핀 일기 기록 부담, 링 장치의 끼임·페이지 이탈·휴대 부피, 리필 속지 규격과 수량, 스티커의 실제 사용가치, 짧은 색연필의 휴대·안전·원가, 카드 한 장 7분 이내 완료와 반복 사용.
