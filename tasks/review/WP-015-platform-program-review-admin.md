# WP-015 플랫폼 프로그램 검수 관리자 도구

- 상태: review
- 담당: app-developer
- PM: wonderpin-pm
- 우선순위: P1
- 목표일: 2026-07-18
- 연관 목표: `이주의 원더핀` 프로그램 후보 검수 효율

## 목적과 범위

아이고고·째깍악어 수집 결과를 로컬 웹에서 보고 원본 링크, 수집 이미지와 요약을 확인한 뒤 `accept` 또는 `decline`으로 판정한다. 수집 실행 버튼과 진행 상태를 제공하고, decline 이력은 삭제하지 않으면서 다음 수집에서 동일 프로그램을 제외한다.

전체 관리자 제품이나 예약 플랫폼을 개발하지 않는다. 프로덕션 배포·운영 DB·로그인 구현 없이 `127.0.0.1`에서만 사용하는 내부 검수 도구로 제한한다.

## 산출물

1. `apps/admin` 로컬 검수 서버와 웹 UI
2. `research/platform-content/review-decisions.json` 판정 이력
3. decline source key·fingerprint 재수집 제외 로직
4. 수집 실행·진행 상태 API와 화면
5. 실행·검증 문서

## 완료 조건

- 프로그램 목록을 출처·카테고리·판정 상태로 필터링할 수 있다.
- 상세에서 원본 링크, 프로그램 요약, 수집 이미지와 OCR 내용을 확인할 수 있다.
- accept·decline 판정이 파일에 영구 기록되고 최초 판단 시점의 프로그램 snapshot이 보존된다.
- decline 항목은 이후 수집에서 source ID 또는 fingerprint가 같으면 제외된다.
- 화면 버튼으로 수집을 실행하고 실행 중·성공·실패 상태와 로그를 볼 수 있다.
- 로컬 주소에만 바인딩하며 외부 게시·운영 DB 변경이 없다.
- 관련 테스트와 실제 로컬 HTTP·브라우저 검증을 통과한다.

- 통합 테스트는 실제 판정 파일과 분리된 임시 데이터로 decline snapshot 보존, accept 변경, 보관 항목 노출, 수집 진행률·성공 상태를 확인했다.

## 미검증·검토 항목

- 화면의 `새로 수집` 버튼은 가짜 수집기로 상태 전이까지 검증했다. 실제 전체 104페이지 재수집은 기존 수집 결과를 덮어쓰므로 사용자 검토 중 직접 실행하도록 남겼다.
- 외부 플랫폼 이미지 중 이미 만료되었거나 응답하지 않는 주소는 숨기고, 확인 가능한 이미지와 다운로드된 로컬 이미지만 표시한다.

## 사용자 승인 경계

- 로컬 실행과 파일 기반 판정은 승인된 범위다.
- 프로덕션 배포, 외부 공개, 운영 DB 연결과 계정·권한 변경은 별도 승인 전 실행하지 않는다.
