# WP-005 인스타그램 두 정기 시리즈 4주 실행안

## 목적과 범위

`1분 원더미션`과 `이주의 원더핀`을 각각 주 1회, 4주간 운영할 카드뉴스 8편을 준비하고 게시 전 검수·성과 기록 방식을 확정한다. 원더팩 제작·테스트 콘텐츠는 이 정기 8편과 분리한다.

실제 외부 게시, 댓글·DM 응답과 광고 집행은 사용자 승인 전 실행하지 않는다.

## 산출물

1. 1분 원더미션 카드뉴스 4편의 카피·슬라이드 구조
2. 이주의 원더핀 큐레이션 4편의 후보·출처·확인 체크리스트
3. 공통 카드뉴스 템플릿 요구사항
4. 게시물별 CTA와 성과 기록표
5. 게시 전 사실·저작권·광고·제휴 표시 점검표

## 완료 조건

- 두 시리즈가 각각 4편이며 주 1회 리듬으로 배치된다.
- 1분 원더미션은 1분 안에 이해·시작할 수 있고 실제 야외활동은 약 1~5분으로 구분된다.
- 이주의 원더핀은 운영주체·연령·지역·가격·일정·예약 링크·확인일을 포함한다.
- 외부 프로그램을 원더핀 자체 상품처럼 표현하지 않는다.
- 사용 권한 없는 이미지·설명문을 복제하지 않는다.
- 정기 콘텐츠 KPI와 원더팩 제품 KPI가 분리된다.

## 사용자 승인 필요

- 인스타그램 실제 게시
- 외부 운영자·가족에게 DM·댓글·문자 발송
- 광고·제휴·유료 집행
- 사진·후기·아동 결과물의 공개 활용

승인 전에는 카피, 디자인 요구사항, 출처 확인과 게시 예약안까지만 준비한다.
