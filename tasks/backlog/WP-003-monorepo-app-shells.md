# WP-003 웹앱 모노레포 초기화와 3개 앱 셸 구현

- 상태: backlog
- 담당: app-developer
- 우선순위: P2
- 목표일: 미정
- 연관 목표: Gate 1~3 통과 후 디지털 확장 후보
- 재개 조건: 카드 유료 수요와 아동 오프라인 창작 행동이 선행 Gate를 통과하고 디지털 확장 Gate가 승인됨

## 목적

가족용 원더핀, 운영자용 원더핀 파트너와 내부 관리자용 앱을 하나의 모노레포에서 실행·검증할 수 있는 개발 기반을 만든다.

현재 카드 우선 전략에서는 구현을 보류한다. 기존 기술 구조는 장기 가설로 보존하되 Gate 1~3의 인력과 일정에 포함하지 않는다.

## 범위

- 패키지 관리자와 워크스페이스 구성 확정
- `apps/web`, `apps/partner`, `apps/admin` Next.js 앱 초기화
- `packages/ui`, `packages/database`, `packages/auth`, `packages/config` 기본 패키지 구성
- 브랜드 토큰과 공통 기본 레이아웃
- 각 앱의 역할을 확인할 수 있는 시작 화면
- lint, typecheck와 build 명령

## 제외

- 실제 Supabase 프로젝트 생성 또는 운영 DB 변경
- 실제 로그인·예약·결제 구현
- 프로덕션 배포
- 관리자에서 AI 에이전트를 실행하는 기능

## 완료 조건

- 루트에서 한 번의 설치로 세 앱과 공유 패키지가 준비된다.
- 세 앱을 각각 로컬에서 실행할 수 있다.
- 모바일, 태블릿과 데스크톱에서 기본 레이아웃이 깨지지 않는다.
- 세 앱이 공통 브랜드 토큰을 사용한다.
- lint, typecheck와 production build가 모두 통과한다.
- README에 실행 명령과 앱별 로컬 주소가 기록되어 있다.

## 검증 방법

- 의존성 설치
- lint
- typecheck
- 세 앱 production build
- 세 앱 로컬 HTTP 응답 확인
- 대표 화면 브라우저 시각 확인

## 승인 필요 항목

- 새 프로덕션 의존성이 필요한 경우 선택 근거를 PM에게 보고한다.
- 외부 서비스 생성, 배포와 운영 DB 연결은 사용자 승인을 받는다.
