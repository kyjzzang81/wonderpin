## 목적

별도 LLM API 없이 Codex에서 PM과 전문 에이전트를 운영하고 모든 업무 상태를 저장소에서 추적할 수 있게 한다.

## 산출물

- 프로젝트 공통 `AGENTS.md`
- PM, 앱개발, 원더팩, SNS, 데이터 조사 에이전트 설정
- 업무, 결정, 위험, 지표 운영 파일
- 3개 웹앱과 공유 패키지의 기술 구조
- 첫 후속 업무 티켓

## 완료 조건

- 5개 에이전트 설정에 이름, 설명, 핵심 지침이 존재한다.
- 외부 행동과 운영 변경의 승인 경계가 명시되어 있다.
- 업무 상태와 상세 업무 파일의 연결 방식이 정의되어 있다.
- 가족용, 파트너용, 관리자용 앱의 구현 위치와 공유 영역이 정의되어 있다.
- 다음 업무가 담당자와 완료 조건을 포함해 준비되어 있다.

## 검증

- TOML 구문 검사
- 필수 파일 및 디렉터리 확인
- 운영 문서 상호 참조 확인

## 결과

- 프로젝트 전용 PM, 앱개발, 원더팩, SNS, 데이터 조사 에이전트를 구성했다.
- 업무, 결정, 위험, 지표와 로드맵 파일을 연결했다.
- 가족용, 파트너용, 관리자용 앱과 공유 패키지의 구현 위치를 확정했다.
- 후속 P0 업무 WP-003을 준비했다.
