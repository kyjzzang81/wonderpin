# 카드 검증 데이터 관리

이 폴더에는 익명화한 Gate 1~2 검증 데이터만 저장한다. 실행 기준은 `docs/business/CARD_VALIDATION_EXECUTION_PLAN.md`를 따른다.

## 파일

- `gate1_participants_template.csv`: 모집·동의·수령·가족 단위 결과
- `usage_sessions_template.csv`: 야외 사용 세션 단위 결과
- `gate2_orders_template.csv`: 주문·배송·환불·변동비·공헌이익

## 개인정보 원칙

- 저장소에는 아동·보호자 실명, 전화번호, 이메일, 상세주소, 얼굴 사진과 정확한 생활 동선을 기록하지 않는다.
- 참여자는 `G1-001`, 구매자는 `G2-001`처럼 익명 ID를 사용한다.
- 실제 연락처·배송주소가 필요하면 사용자 승인 후 접근이 제한된 외부 수단에 보관하고, 이 CSV에는 대응 ID만 기록한다.
- 후기·사진·그림의 홍보 활용 동의는 연구 참여 동의와 분리한다.

템플릿의 빈 행은 실적이 아니다. 실제 실행 후 출처와 확인일이 있는 값만 추가한다.
