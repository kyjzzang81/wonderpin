# 원더핀 브랜드 및 서비스 구조

- 기준일: 2026-07-17
- 현재 제품 단계: 휴대형 야외 탐험 카드

## 1. 브랜드 메시지

### 메인 슬로건

> **아이의 질문이 시작되는 곳.**

### 브랜드 소개

모든 아이는 세상을 발견하는 **원더러**입니다. 원더핀은 작은 원더러들이 평범한 산책길과 놀이터를 더 깊이 보고, 질문하고, 발견하도록 돕습니다.

### 현재 사업용 메시지

> 한국의 일상 야외공간을 5~9세 아이의 탐구 경험으로 바꾸는 휴대형 탐험 콘텐츠

### 장기 비전

> 아이·가족·장소·운영자가 탐구 콘텐츠를 만들고 이용하는 Family Exploration Platform

현재 제품과 장기 플랫폼 비전을 혼동하지 않는다. 외부 소개에서는 아직 구현하지 않은 예약·운영자 SaaS·AR·아동 UGC를 현재 서비스처럼 표현하지 않는다.

## 2. 브랜드 용어

| 용어 | 현재 정의 | 사용 예시 |
| --- | --- | --- |
| **원더핀** | 야외 탐험 카드와 후속 탐구 경험을 만드는 브랜드 | “오늘 아이와 원더핀 하나 해볼까요?” |
| **원더팩** | 5~9세 가족이 야외에서 사용하는 휴대형 탐험 카드 상품 | “원더팩 한 장을 뽑고 주변을 살펴보세요.” |
| **원더 미션** | 카드 한 장에 담긴 약 5분의 관찰·비교·추론 활동 | “오늘의 원더 미션은 바람의 흔적 찾기예요.” |
| **원더러** | 원더팩으로 세상을 질문하고 발견하는 어린이 | “원더러가 발견한 한 문장을 남겨주세요.” |
| **장소 원더팩** | 기본 카드 검증 후 특정 장소에 맞춰 만드는 확장팩 | “서울에너지드림센터 장소 원더팩” |
| **원더핀 파트너** | 장기적으로 운영자 도구가 검증될 때 사용할 명칭 | 현재 외부 제품명으로 적극 홍보하지 않음 |

`탐구팩`, `미션팩`, `활동지` 대신 제품명 `원더팩`을 사용한다. 첫 소개에서는 `휴대형 야외 탐험 카드 원더팩`으로 설명한다.

## 3. 탐구 문법

모든 원더 미션은 다음 문법을 따른다.

1. **찾기**: 주변에서 하나를 발견한다.
2. **비교하기**: 다른 것과 차이를 살핀다.
3. **추론하기**: 왜 그런지 아이의 생각을 말한다.
4. **표현하기**: 한 문장·그림·선택으로 남긴다.

정답을 맞히는 학습지가 아니라 아이가 근거를 보고 자기 생각을 만드는 경험으로 설계한다.

## 4. 제품 전개 순서

### 트랙 1. 원더팩 기본 카드

- 한국 생활권 야외에서 범용으로 사용
- 화면 없이 휴대하고 한 장 약 5분
- 실제 결제와 반복 사용 검증

### 트랙 2. 아이 창작 오프라인 확장 키트

- 완성 카드 뒤에 빈 카드와 질문 템플릿 제공
- 아이가 만든 미션을 다른 가족이 플레이
- 디지털 플랫폼 전 창작·성취·상호 플레이 검증

### 트랙 3. 계절·장소 확장팩

- 봄·비·바람·밤산책 등 계절·상황팩
- 서울에너지드림센터 등 특정 장소팩
- 기본팩 구매자의 추가 구매 검증

### 트랙 4. 디지털·운영자 플랫폼

- 보호자 계정과 비공개 미션 제작
- 관리되는 장소에서 QR·위치·AR 확장
- 장소 프로그램과 운영자 도구는 거래 수요가 확인될 때 재검토

네 트랙은 동시에 개발하지 않고 앞 단계의 Gate를 통과한 뒤 다음 단계로 이동한다.

## 5. SNS 콘텐츠

| 시리즈 | 빈도 | 내용 | 핵심 지표 |
| --- | --- | --- | --- |
| **1분 원더미션** | 주 1회 | 카드뉴스를 보고 바로 시작하는 간단한 야외 미션 | 도달·저장·공유·실행 반응 |
| **이주의 원더핀** | 주 1회 | 외부 플랫폼·공식 채널에서 확인한 이번 주 아동 프로그램 큐레이션 | 저장·링크 행동·지역·연령·가격 수요 |
| **원더팩 제작·테스트** | 월 1~2회 비정기 | 시제품 제작, 가족 사용과 판매 검증 과정 | 신청·수령·사용·결제 |

`1분 원더미션`의 1분은 게시물을 이해하고 시작하는 시간이며, 실물 카드 상품의 `원더 미션`은 한 장 약 5분 활동이다. 둘을 같은 시리즈명으로 사용하지 않는다.

정기 콘텐츠는 계정 성장과 고객 학습, 원더팩 비정기 콘텐츠는 사용·결제 검증으로 나누어 평가한다. 아동 창작 미션 콘텐츠는 오프라인 확장 키트 Gate를 시작한 뒤에만 발행한다.

## 6. 현재 비목표 표현

- `프로그램 예약 플랫폼`을 현재 제품처럼 소개하지 않는다.
- `운영자 SaaS`를 출시된 서비스처럼 소개하지 않는다.
- `아이들이 AR을 자유롭게 배치한다`고 예고하지 않는다.
- 국내 최초, 유일한 야외 탐험 카드라고 주장하지 않는다.
- 사용 근거 없이 교육효과를 확정적으로 표현하지 않는다.

## 7. 서비스 구조 요약

현재 채널 성장 루프:

> 1분 원더미션·이주의 원더핀 발견 → 저장·공유·실행·링크 확인 → 반복 방문 → 연령·장소·프로그램 수요 학습

현재 제품 검증 퍼널:

> 원더팩 비정기 게시물 → 테스트 신청·구매 → 야외 사용 → 반복 사용·아이 기록 → 확장팩 구매

후속:

> 원더핀 미션 플레이 → 아이가 오프라인 카드 제작 → 다른 가족이 플레이 → 관리 장소·디지털 제작 → 장소·운영자 플랫폼
