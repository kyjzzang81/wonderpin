# 원더핀 비주얼 브랜드 가이드

이 문서는 원더핀 로고와 핵심 컬러를 일관되게 사용하기 위한 최소 기준이다. 원본 브랜드 보드와 실사용 로고 파일은 `assets/brand/`에서 관리한다.

## 1. 브랜드 컬러

| 역할 | 이름 | HEX | RGB | 권장 용도 |
| --- | --- | --- | --- | --- |
| 브랜드 컬러 | Indigo Purple | `#5A3FA3` | `90, 63, 163` | 로고, 주요 제목, 핵심 버튼, 브랜드를 대표하는 면 |
| 강조 컬러 | Soft Pink | `#F28CA6` | `242, 140, 166` | 아이콘의 별, 배지, 선택 상태, 짧은 강조 요소 |

### 사용 원칙

- Indigo Purple을 기본 브랜드 인지 색상으로 사용한다.
- Soft Pink는 시선을 모으는 작은 요소에 제한해 사용한다. 넓은 면이나 긴 본문에는 사용하지 않는다.
- 두 색을 함께 사용할 때는 Indigo Purple이 주색, Soft Pink가 보조색이 되도록 비중을 유지한다.
- 흰색 배경을 기본으로 하며, 본문 텍스트는 가독성을 위해 별도의 짙은 중립색을 사용한다.
- 작은 글자나 핵심 조작 요소에 색을 적용할 때는 실제 배경과의 명도 대비를 확인한다.

### 디자인 토큰 예시

```css
:root {
  --color-brand: #5a3fa3;
  --color-accent: #f28ca6;
}
```

## 2. 로고 파일

| 파일 | 용도 |
| --- | --- |
| `assets/brand/wonderpin-logo-ko.png` | 한글 로고, 원본 해상도 기반 투명 PNG |
| `assets/brand/wonderpin-logo-ko@4x.png` | 한글 로고, 고해상도 배치용 투명 PNG |
| `assets/brand/wonderpin-logo-en.png` | 영문 로고, 원본 해상도 기반 투명 PNG |
| `assets/brand/wonderpin-logo-en@4x.png` | 영문 로고, 고해상도 배치용 투명 PNG |
| `assets/brand/wonderpin-brand-board.png` | 전달받은 원본 브랜드 보드 |

### 로고 사용 원칙

- 로고의 비율, 글자 간격, 색상과 별 모양을 임의로 바꾸지 않는다.
- 로고 주변에는 최소한 별 모양 한 개 높이 정도의 여백을 확보한다.
- 복잡하거나 브랜드 컬러와 비슷한 배경 위에는 직접 올리지 않는다. 흰색 또는 충분히 밝고 단순한 배경을 사용한다.
- 일반 화면과 문서에는 기본 PNG를 사용하고, 큰 출력물이나 고밀도 화면에는 `@4x` 파일을 사용한다.
- 제공된 원본이 작은 래스터 이미지이므로 대형 인쇄물에는 추후 벡터 원본(`SVG`, `AI`) 확보를 권장한다.

## 3. 브랜드 인상

> 상상력과 창의성, 표현이 즐거운 브랜드

시각 표현은 부드럽고 친근하게 구성하되, 많은 색을 동시에 사용하기보다 Indigo Purple과 Soft Pink가 명확히 기억되도록 한다.
