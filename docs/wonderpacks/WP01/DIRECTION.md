# 첫 원더팩 기획 방향

- 기준일: 2026-07-17
- 상태: 휴대형 야외 탐험 카드로 방향 변경

## 1. 첫 원더팩의 역할

첫 원더팩은 서울에너지드림센터 전용 PDF·웹 활동지가 아니라, 5~9세 가족이 산책길·놀이터·공원에서 반복 사용하는 휴대형 야외 탐험 카드다.

첫 제품은 다음 질문에 답한다.

- 보호자가 카드를 꺼내 1분 안에 시작할 수 있는가?
- 카드 한 장이 약 5분 안에 끝나는가?
- 아이가 찾기에서 비교·이유·표현으로 넘어가는가?
- 가족이 서로 다른 날 다시 사용하는가?
- 무료 콘텐츠가 아니라 실물 상품에 실제 결제하는가?

## 2. 변경 이유

- eeBoo·Melissa & Doug 등은 휴대형 야외 찾기 카드의 사용성과 가격 시장을 보여준다.
- 국내 공개 검색에서는 한국 생활권·계절과 관찰·추론을 결합한 대표 휴대형 카드 브랜드가 뚜렷하지 않았다.
- 대표자는 초기 콘텐츠를 직접 제작할 수 있고 자기자금 500만 원 안에서 소량 인쇄·판매 검증이 가능하다.
- 웹앱·AR·운영자 SaaS보다 빠르게 실제 결제와 반복 행동을 확인할 수 있다.

## 3. 대상과 사용 맥락

- 보호자 동반 5~9세
- 아파트 산책로, 놀이터, 동네 공원, 가로수길, 하천공원
- 카드 한 장 5분, 한 번에 1~3장
- 별도 재료와 사전 지식 없음
- 화면을 보지 않고 주변을 관찰

## 4. 콘텐츠 구성

### 기본 카드 18장

- 색과 모양
- 밝음과 어두움
- 소리의 거리와 방향
- 바람과 움직임
- 반복되는 무늬와 규칙
- 물·비·사람·동물이 남긴 흔적

### 장면 카드 6장

- 놀이터 2장
- 공원 2장
- 산책길·거리 2장

### 보조 구성

- 보호자 사용법 1장
- 안전 원칙 1장
- 아이 발견 기록지 4장
- 휴대 파우치 또는 밴드

## 5. 카드 형식

앞면:

- 오늘의 장면
- 아이에게 읽어줄 질문
- 약 5분 표시

뒷면:

- 한 단계 더 비교·추론하는 질문
- 5~6세 / 7~9세 질문 난이도
- 보호자 도움말
- 안전 주의

## 6. 탐구 구조

모든 카드는 `관찰 → 비교 → 추론 → 표현`을 사용한다.

예시:

> 바람에 움직이는 것 두 개를 찾아보세요. 무엇이 더 빨리 움직이나요? 왜 그럴까요? 아이가 한 말을 한 문장으로 남겨보세요.

정답과 과학 설명은 카드의 중심이 아니다. 부모가 아이의 말을 끌어낼 수 있는 질문이 중심이다.

## 7. 안전 기준

- 자연물과 생물을 채집·훼손하지 않는다.
- 뛰기, 등반, 눈 감고 이동하기를 요구하지 않는다.
- 차도·주차장·공사구역·물가·사유지 접근을 유도하지 않는다.
- 낯선 사람, 얼굴, 차량번호, 집과 학교 촬영을 요구하지 않는다.
- 폭염·한파·호우·미세먼지 상황에서는 중단한다.

## 8. 제공·가격 방향

- 첫 30세트는 사용성 테스트용 소량 시제품이다.
- 무료 테스트 이후 실제 결제 가능한 파일럿을 별도 판매한다.
- 가격은 5,900원으로 고정하지 않고 구성·원가·배송비를 반영한 두 안을 비교한다.
- 실제 결제, 환불, 14일 내 첫 사용과 30일 내 반복 사용을 함께 측정한다.

## 9. 첫 베타 성공 기준

- 시제품 수령 가족 15팀 이상
- 실제 야외 사용 가족 10팀 이상
- 서로 다른 날 두 번째 사용 가족 5팀 이상
- 카드 한 장 7분 이내 완료율 70% 이상
- 별도 준비 없이 시작한 가족 70% 이상
- 아이의 말·그림 등 실행 근거 10건 이상

## 10. 후속 확장

### 오프라인 창작 키트

기본 카드 사용 후 빈 미션 카드와 질문 템플릿을 제공한다. 아이가 만든 미션을 다른 가족이 설명 없이 플레이하고 제작 아이가 수정하는지 확인한다.

### 장소 확장팩

서울에너지드림센터는 기본 카드의 유료·반복 사용 검증 후 추진하는 첫 장소 확장팩 후보다. 기존 조사와 콘텐츠 기획은 폐기하지 않고 후속 자료로 보관한다.

### 플랫폼

아동 창작이 오프라인에서 반복될 때만 보호자 계정·비공개 코드·관리 장소 순으로 디지털화한다. AR과 공개 UGC는 초기 범위에서 제외한다.
