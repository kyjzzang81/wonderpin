# 원더미션을 만드는 사람을 위한 아동 발달 자습서

부제: 만 4~9세의 탐구·창의·성취·모험을 이해하고 5분 야외 미션으로 바꾸는 법

- 원더핀 내부 학습용
- 기준일: 2026-07-17
- 읽는 시간: 약 3~4시간
- 권장 방식: 7일 동안 하루 한 단원 + 실습

> 이 문서는 아동을 진단하거나 치료하기 위한 자료가 아니다. 발달 이정표는 많은 아이에게 흔히 보이는 행동을 이해하기 위한 참고 자료다. 실제 미션의 적합성은 개별 아이와 가족의 현장 사용을 통해 확인해야 한다.

# 들어가며: 이 교재의 목표

원더미션을 잘 만들기 위해 아동발달학 전체를 공부할 필요는 없다. 대신 네 가지를 정확히 알아야 한다.

1. 같은 질문도 아이의 연령과 경험에 따라 어떤 부담으로 느껴지는가.
2. 아이가 스스로 탐색하도록 두면서도 성인이 언제, 얼마나 도와야 하는가.
3. 탐구·창의·성취·모험을 추상적인 교육 가치가 아니라 관찰 가능한 행동으로 어떻게 바꾸는가.
4. 흥미로운 도전과 불필요한 위험을 어떻게 구분하는가.

이 교재를 다 읽고 나면 다음 일을 할 수 있어야 한다.

- 만 4~5세, 6~7세, 8~9세용 질문의 차이를 설명한다.
- 미션 하나가 요구하는 작업기억, 주의, 언어, 운동 부담을 찾아낸다.
- 정답을 말해주지 않고 아이의 생각을 이어주는 힌트를 설계한다.
- `찾기 → 비교 → 추론 → 표현` 구조로 5분 야외 미션을 만든다.
- 탐구·창의·성취·모험 미션을 각각 설계하고 안전하게 검수한다.
- 미션 실패를 아이의 실패가 아니라 설계 개선 정보로 기록한다.

## 공부할 때 지켜야 할 세 가지

첫째, 연령표를 합격선으로 사용하지 않는다. 만 5세라고 해서 모두 같은 문장을 이해하거나 같은 방식으로 말하지 않는다. 언어, 경험, 흥미, 감각 특성, 피로, 장소의 익숙함이 참여 방식에 영향을 준다.

둘째, 교육효과를 먼저 약속하지 않는다. 이론적으로 좋아 보이는 질문도 현장에서 시작하지 못하거나 보호자가 대부분 대신한다면 원더미션으로 작동하지 않은 것이다.

셋째, 아이의 말만 보지 않는다. 가리키기, 고르기, 몸짓, 표정, 움직임, 그림도 생각을 표현하는 방법이다.

# 1장. 발달을 보는 기본 관점

## 1.1 발달은 여러 영역이 동시에 작동한다

아이가 공원에서 “바람에 움직이는 것 두 개를 찾아보자”는 미션을 수행한다고 생각해보자. 이 짧은 활동에도 여러 능력이 함께 필요하다.

- 질문을 듣고 기억하는 언어와 작업기억
- 주변 자극 중 움직임을 고르는 선택적 주의
- 안전하게 이동하고 시선을 옮기는 운동 능력
- 두 대상을 비교하는 인지 능력
- 자기 생각을 말하거나 몸짓으로 보이는 표현 능력
- 보호자와 차례를 주고받는 사회정서와 자기조절

따라서 “이 질문은 인지 미션”처럼 한 영역으로만 분류하면 실제 어려움을 놓치기 쉽다. 미션을 검수할 때는 아이가 동시에 수행해야 하는 부담을 세어야 한다.

### 부담 세기 연습

다음 미션을 살펴보자.

> 빨간 것 세 개와 둥근 것 두 개를 찾아서, 크기순으로 놓인 것처럼 손가락으로 가리킨 다음, 가장 마음에 드는 것의 이름을 지어보세요.

이 미션은 찾을 조건 두 개, 개수 기억, 분류, 순서화, 가리키기, 선택, 이름 짓기를 동시에 요구한다. 각각은 가능할 수 있어도 한 카드에 겹치면 시작이 어려워진다.

수정하면 다음과 같다.

> 둥근 것 두 개를 찾아보세요. 어느 쪽이 더 커 보이나요?

한 번에 하나의 비교 기준만 남겼다. 창의 활동을 넣고 싶다면 다음 카드나 선택 질문으로 분리한다.

> 둘 중 하나에 재미있는 별명을 붙여볼까요?

## 1.2 발달은 평균 경로이지 시간표가 아니다

CDC의 발달 이정표는 해당 나이에 약 75% 이상의 아동에게 관찰되는 행동을 정리한 자료다. 이는 가족이 발달을 관찰하고 우려가 있을 때 전문가와 상의하도록 돕는 자료이며, 표준화된 발달 선별검사를 대신하지 않는다.

원더핀에서는 이정표를 다음 용도로만 사용한다.

- 질문이 지나치게 긴지 점검하는 시작점
- 말하기 외의 표현 방법이 필요한지 확인하는 참고
- 놀이, 규칙, 비교, 이야기 등 연령별 실험 가설을 만드는 자료

다음과 같이 사용하면 안 된다.

- “만 5세라면 반드시 이유를 문장으로 말해야 한다.”
- “미션을 못 했으니 발달이 느리다.”
- “이 카드는 두뇌 발달을 보장한다.”

## 1.3 아이의 능력은 상황에 따라 달라진다

익숙한 놀이터에서는 잘 말하던 아이가 낯선 공원에서는 조용할 수 있다. 배가 고프거나 피곤하면 평소 가능한 규칙도 놓칠 수 있다. 시끄러운 장소에서는 말소리를 듣는 데 더 많은 에너지가 들 수 있다.

그래서 관찰 기록에는 성공 여부만 적지 않는다.

- 장소의 익숙함
- 소음과 사람 수
- 날씨와 피로
- 아이가 고른 활동인지 여부
- 보호자가 제공한 도움
- 말 이외에 사용한 표현

## 1.4 강점에서 시작한다

발달적합실제는 아이를 결핍 목록으로 보는 대신, 아이가 가진 흥미·언어·문화·경험·능력을 학습의 자원으로 본다. 자동차를 좋아하는 아이는 바퀴 자국과 움직임에 관심을 보일 수 있고, 이야기를 좋아하는 아이는 같은 흔적을 상상의 단서로 확장할 수 있다.

원더미션은 하나의 정답 경로보다 여러 진입점을 제공해야 한다.

- 보기: 색, 모양, 움직임, 흔적
- 듣기: 가까운 소리, 먼 소리, 반복되는 소리
- 움직이기: 안전 경계 안에서 방향 선택
- 표현하기: 말, 손가락, 몸짓, 그림, 선택

### 1장 핵심 정리

- 한 미션은 여러 발달 영역을 동시에 요구한다.
- 연령 이정표는 진단이나 합격선이 아니라 설계 가설을 만드는 참고 자료다.
- 성공 여부는 아이뿐 아니라 장소, 피로, 소음, 성인 도움의 영향을 받는다.
- 말하기만을 생각의 증거로 취급하지 않는다.

### 스스로 답해보기

1. 내가 만든 미션이 동시에 기억하게 하는 조건은 몇 개인가?
2. 말로 답하기 어려운 아이가 사용할 수 있는 다른 표현은 있는가?
3. 아이가 시작하지 못했을 때 아이의 능력 외에 점검할 상황 요인은 무엇인가?

# 2장. 만 4~5세의 참여를 이해하기

## 2.1 흔히 보이는 참여 방식

만 4세 무렵에는 가장놀이를 하고, 간단한 질문에 답하며, 익숙한 이야기의 다음 장면을 예상하고, 색을 이름 붙이는 행동이 흔히 관찰된다. 만 5세 무렵에는 두 사건이 있는 이야기를 만들거나 들은 이야기에 대한 간단한 질문에 답하고, 놀이 규칙과 차례를 따르며, 흥미 있는 활동에 5~10분 정도 주의를 유지하는 행동이 흔히 관찰된다.

이 내용을 카드 설계로 번역하면 다음과 같다.

- 지시는 한 문장으로 시작한다.
- 한 번에 찾을 대상은 1~2개가 적절한 출발점이다.
- 결과가 바로 보이는 행동을 먼저 둔다.
- 이유를 길게 설명시키기보다 고르기, 가리키기, 짧게 말하기를 허용한다.
- 상상과 역할놀이를 관찰 활동과 연결한다.
- 선택지는 2~3개로 좁힌다.

## 2.2 작동하기 쉬운 미션 구조

> 노란 것을 하나 찾아보세요. 손가락으로 가리켜도 좋아요.

이 질문은 한 대상, 한 속성, 한 행동만 요구한다.

한 단계 확장한다.

> 가까운 노란 것과 먼 노란 것을 하나씩 찾아보세요. 어느 쪽이 더 커 보여요?

처음부터 이 문장을 모두 읽기보다 첫 발견 뒤에 비교 질문을 덧붙이는 편이 좋다.

창의성을 연결한다.

> 노란 것에 햇빛 나라 이름을 하나 붙여볼까요?

아이가 이름을 말하지 않으면 보호자가 두 이름을 제안하고 고르게 할 수 있다.

## 2.3 어려움이 나타나는 신호

- 질문을 다시 읽어도 첫 행동을 시작하지 않는다.
- 두 번째 대상을 찾는 동안 첫 번째 대상을 잊는다.
- 보호자의 마지막 말을 그대로 반복한다.
- 주변을 보기보다 카드나 보호자 얼굴만 본다.
- 다른 놀이로 반복해서 전환한다.
- 쓰기나 그리기 단계에서 활동이 멈춘다.

이 신호는 “못한다”는 판정이 아니다. 미션의 조건을 줄이거나 아이가 이미 시작한 놀이에 미션을 연결하라는 정보다.

## 2.4 피해야 할 패턴

- 세 단계 이상의 지시를 한 번에 읽기
- 긴 이유 설명을 완료 조건으로 삼기
- 읽기나 글쓰기를 필수로 만들기
- 빨리 찾기 경쟁
- 정답이 나올 때까지 반복 질문하기
- 아이가 보고 있는 대상을 무시하고 카드가 정한 대상만 찾게 하기

## 2.5 보호자의 적절한 도움

좋지 않은 도움:

> 저기 나뭇잎 있잖아. 저게 바람에 움직이네. 나뭇잎이라고 답해.

더 나은 도움:

> 나무 쪽과 바닥 쪽 중 어디부터 볼까?

가장 적은 도움은 기다리는 것이다. 아이가 질문을 처리하고 주변을 둘러볼 수 있도록 5~10초를 준다.

### 4~5세 설계 카드

| 항목 | 시작 기준 |
| --- | --- |
| 문장 | 한 문장, 구체적인 행동 동사 |
| 단계 | 한 단계 후 다음 질문 공개 |
| 대상 | 1~2개 |
| 비교 | 크다/작다, 가깝다/멀다, 빠르다/느리다처럼 한 기준 |
| 표현 | 가리키기, 고르기, 몸짓, 한두 단어 허용 |
| 창의 | 이름 붙이기, 소리 흉내, 짧은 가장놀이 |
| 도움 | 기다리기 → 두 선택지 → 한 번 시범 |

# 3장. 만 6~7세의 참여를 이해하기

## 3.1 전환기의 특징

6~7세는 놀이 중심 경험에서 학교식 규칙과 기호 사용으로 이동하는 시기다. 하지만 읽기와 쓰기의 숙련도 차이는 크다. 글자를 읽을 수 있다는 이유로 카드가 학습지처럼 바뀌면 야외 관찰보다 읽기 수행이 중심이 되기 쉽다.

이 연령에서는 다음 활동을 실험하기 좋다.

- 두 대상의 공통점과 차이 찾기
- 비교 기준 하나를 적용하기
- 간단한 예측 후 실제로 확인하기
- 규칙 하나를 기억하며 탐색하기
- 관찰한 것을 짧은 이유와 연결하기
- 보호자와 번갈아 단서 만들기

## 3.2 작동하기 쉬운 미션 구조

> 같은 재료로 만들어진 것 두 개를 찾아보세요.

> 둘은 비를 맞으면 어떻게 달라질까요? 그렇게 생각한 단서를 하나 말해보세요.

핵심은 “정답을 설명하기”가 아니라 “관찰한 단서를 사용해 예상하기”다. 틀린 예측도 관찰 근거가 있다면 탐구 행동으로 인정한다.

## 3.3 규칙은 하나씩 늘린다

실행기능에는 정보를 잠시 기억하는 작업기억, 충동적인 반응을 멈추는 억제, 규칙이나 관점을 바꾸는 인지적 유연성이 포함된다.

예를 들어 “빨간 것은 건너뛰고 움직이는 것만 찾되 사람이 만든 것은 제외하자”는 문장은 세 규칙을 동시에 기억하게 한다. 더 나은 방식은 규칙을 순서대로 여는 것이다.

1. 움직이는 것 하나 찾기
2. 그것이 자연의 힘으로 움직이는지 사람이 움직이는지 고르기
3. 다른 종류 하나 더 찾기

## 3.4 어려움이 나타나는 신호

- 비교보다 대상 수집에만 몰입한다.
- 이유 질문에서 보호자의 말을 복창한다.
- 규칙이 바뀌었는데 처음 규칙만 계속 적용한다.
- 한 번 실패한 뒤 카드 전체를 포기한다.
- 쓰기에 시간이 걸려 야외 탐색이 중단된다.

## 3.5 피해야 할 패턴

- 두 가지 이상의 비교 기준을 동시에 요구하기
- 과학 용어를 먼저 가르친 뒤 확인 질문하기
- 이유를 하나의 모범답안으로 유도하기
- 읽기·맞춤법·그림 완성도를 성공 기준으로 삼기
- 보호자와 속도 경쟁을 시키기

### 6~7세 설계 카드

| 항목 | 시작 기준 |
| --- | --- |
| 문장 | 짧은 두 문장까지 가능, 핵심 행동을 먼저 제시 |
| 단계 | 두 단계, 필요하면 카드 앞뒤로 분리 |
| 대상 | 2개 중심 |
| 비교 | 한 기준 또는 아이가 기준을 선택 |

| 표현 | 말, 선택, 간단한 그림·표시 |
| 창의 | 익숙한 규칙 바꾸기, 단서 만들기 |

# 4장. 만 8~9세의 참여를 이해하기

## 4.1 더 복잡한 생각보다 더 큰 주도권

8~9세에게 난이도를 높인다고 해서 설명을 길게 하거나 지식을 많이 요구할 필요는 없다. 좋은 확장은 아이가 비교 기준, 탐색 방법, 기록 방식 또는 다음 미션을 직접 결정하게 하는 것이다.

이 연령에서는 다음 행동을 실험하기 좋다.

- 스스로 비교 기준 만들기
- 관찰 → 예측 → 증거 → 생각 수정의 흐름 경험하기
- 여러 대상을 규칙에 따라 분류하기
- 다른 사람이 풀 수 있는 단서 만들기
- 같은 현상을 다른 관점으로 설명하기
- 자신의 미션을 시험하고 수정하기

## 4.2 작동하기 쉬운 미션 구조

> 이 장소에서 반복되는 무늬나 간격을 세 가지 찾아보세요.

> 셋을 한 가지 규칙으로 묶어 이름을 붙여보세요. 친구가 그 규칙을 알아낼 수 있도록 단서도 하나 만드세요.

이 미션은 정해진 답을 찾는 대신 아이가 기준을 만들고 다른 사람의 관점을 예상하게 한다.

## 4.3 설명이 길다고 탐구가 깊은 것은 아니다

아이가 풍부한 이야기를 하더라도 관찰 대상과 연결되지 않을 수 있다. 이때 이야기를 중단시키기보다 증거를 부드럽게 다시 연결한다.

> 재미있는 생각이네. 네 이야기와 연결되는 실제 흔적을 여기서 하나 찾아볼까?

반대로 말이 짧아도 손가락으로 정확한 차이를 가리킨다면 중요한 관찰 증거다.

## 4.4 어려움이 나타나는 신호

- 찾기 활동이 너무 쉬워 바로 이탈한다.
- 설명은 길지만 관찰 근거가 없다.
- 완벽한 답을 만들려다 시작을 늦춘다.
- 보호자와 정답 논쟁을 한다.
- 미션 만들기에서 규칙을 너무 많이 넣어 다른 사람이 시작하지 못한다.

## 4.5 피해야 할 패턴

- 유아적인 말투와 지나치게 명백한 찾기
- 지식 퀴즈로 난이도 높이기
- 결과물의 예쁨이나 글의 길이 평가하기
- 아이가 만든 분류 기준을 성인 기준으로 바로 교정하기
- 다른 아이가 실패하면 제작 아이의 실패로 판정하기

# 5장. 놀이와 안내된 놀이

## 5.1 놀이의 세 가지 감각

NAEYC가 정리한 놀이의 중요한 특성은 아이의 선택, 탐색하며 의미를 만드는 경이, 발견에서 오는 즐거움이다. 성인이 활동의 모든 순서와 답을 지시할수록 아이는 그것을 놀이로 느끼기 어렵다.

하지만 “자유롭게 놀게 두기”만으로 원더미션의 목표가 생기는 것은 아니다. 안내된 놀이는 아이가 주도권을 유지하는 가운데 성인이 환경, 질문, 제안, 재료로 탐색을 확장하는 중간 지점이다.

## 5.2 원더미션에서 성인의 역할

성인은 교사가 아니라 다음 역할을 한다.

- 안전 경계를 정하는 사람
- 질문을 읽어주는 사람
- 아이가 보고 있는 것을 따라가는 관찰자
- 막혔을 때 가장 적은 힌트를 주는 조력자
- 아이의 말을 정답 평가 없이 되돌려주는 대화 상대

## 5.3 선택권은 작고 구체적으로

선택권이 많다고 항상 좋은 것은 아니다. 특히 어린 아이에게 “뭐든 해봐”는 시작 부담이 될 수 있다.

좋은 선택:

- 나무 쪽과 바닥 쪽 중 어디부터 볼까?
- 말로 할까, 손가락으로 가리킬까?
- 첫 번째와 두 번째 중 어느 것을 이야기 주인공으로 할까?

부담이 큰 선택:

- 이 공원에서 하고 싶은 탐구를 자유롭게 정해봐.
- 무엇이든 창의적으로 표현해봐.

## 5.4 어른이 질문을 빼앗는 순간

아이가 침묵하면 성인은 불편함을 느끼고 곧 답을 말하기 쉽다. 질문을 연속으로 던지는 것도 답을 말하는 것만큼 부담이 될 수 있다.

> 왜? 또 왜? 그건 왜 그렇게 됐을까? 진짜 이유가 뭘까?

한 번에 하나만 묻고 기다린다. 아이가 답하면 평가 대신 관찰을 되돌려준다.

> 잎이 많이 흔들려서 바람이 세다고 생각했구나.

## 5.5 놀이 여부 자가점검

- 아이가 대상, 순서, 방법, 표현 중 하나를 선택했는가?
- 보호자가 말한 시간보다 아이가 본 시간이 길었는가?
- 예상 밖의 답을 허용했는가?
- 중단하거나 다른 카드로 바꿀 수 있었는가?
- 완료 뒤 아이가 다음 행동을 제안했는가?

# 6장. 실행기능과 자기조절

## 6.1 세 가지 핵심 기능

작업기억은 지금 필요한 정보를 잠시 붙들어 두는 능력이다. 억제는 먼저 떠오른 행동을 잠시 멈추고 규칙에 맞게 행동하는 능력이다. 인지적 유연성은 규칙, 관점, 방법을 바꾸는 능력이다.

Harvard 발달센터는 아이가 이 능력을 완성된 상태로 태어나는 것이 아니라, 관계와 반복 연습 속에서 발달시킬 잠재력을 가지고 태어난다고 설명한다. 활동은 연령과 개별 능력에 맞춰야 하며, 아이가 준비될수록 성인의 지원을 줄여 독립성을 높이는 방향이 중요하다.

## 6.2 카드에서 보이지 않는 실행기능 부담

| 카드 요소 | 주로 요구되는 부담 |
| --- | --- |
| 두 개의 조건 기억 | 작업기억 |
| 찾고 싶은 대상을 건너뛰기 | 억제 |
| 중간에 분류 기준 바꾸기 | 인지적 유연성 |
| 차례 기다리기 | 억제와 정서 조절 |
| 계획대로 안 될 때 다시 시도 | 유연성과 정서 조절 |

## 6.3 부담을 조절하는 방법

- 규칙을 그림이나 손가락 표시로 보이게 한다.
- 한 단계를 끝낸 뒤 다음 단계를 공개한다.
- 규칙 전환 전에 “이제 규칙을 바꿔볼게”라고 알린다.
- 기억해야 할 수를 줄이고 현장에서 다시 볼 수 있게 한다.
- 실패에 벌점이나 시간 압박을 붙이지 않는다.
- 쉬운 시작을 제공하고 성공 뒤 선택적으로 확장한다.

## 6.4 자기조절을 성격으로 평가하지 않는다

“집중력이 없다”, “끈기가 없다”는 표현은 미션 개선에 도움이 되지 않는다. 관찰 가능한 행동으로 바꾼다.

- 질문을 읽은 뒤 20초 동안 주변을 보지 않았다.
- 두 번째 규칙을 들은 뒤 첫 번째 규칙으로 세 번 행동했다.
- 한 번 실패한 뒤 카드를 내려놓았다.
- 선택지를 두 개로 줄이자 다시 시작했다.

EEF는 유아 자기조절 전략이 긍정적인 가능성을 보이지만 근거의 양과 확실성이 제한적임을 함께 제시한다. 따라서 원더핀은 “자기조절 향상”을 상품 효과로 단정하지 않고, 재시도·기다림·도움 후 주도권 회복 같은 과정만 관찰한다.

### 실행기능 검수 질문

1. 아이가 머릿속에 동시에 유지해야 할 조건은 몇 개인가?
2. 규칙이 바뀌는 순간이 명확한가?
3. 실패 후 다시 시작할 더 쉬운 경로가 있는가?
4. 보호자가 도움을 줄인 뒤 아이가 다시 주도할 수 있는가?

# 7장. 탐구: 정답보다 증거를 찾는 과정

## 7.1 어린 아이도 탐구할 수 있다

미국 국립과학원 보고서는 어린 아이도 의미 있는 현상을 관찰하고, 자료와 정보를 모으고, 설명을 만들고, 자신의 추론을 다른 사람과 나누는 과학·공학 활동에 참여할 수 있다고 정리한다. 이 과정은 고정된 순서로만 일어나지 않으며 아이의 연령, 경험, 맥락에 따라 다양한 모습으로 나타난다.

원더미션의 탐구는 과학 지식을 맞히는 퀴즈가 아니다.

> 관찰 → 비교 → 예상 또는 설명 → 다시 보기 → 생각 바꾸기

이 흐름을 짧게 경험하게 하는 것이다.

## 7.2 좋은 현상은 눈앞에서 확인할 수 있다

좋은 탐구 대상:

- 바람에 따라 다르게 움직이는 잎과 깃발
- 그늘과 햇빛에서 달라 보이는 색
- 재료에 따라 다른 소리
- 사람과 비가 남긴 흔적
- 반복되는 무늬와 간격
- 경사에 따라 달라지는 굴러감

피해야 할 대상:

- 현장에서 확인할 수 없는 지식 문제
- 정답을 알려면 인터넷 검색이 필요한 질문
- 생물 채집이나 훼손이 필요한 관찰
- 정확한 측정 도구 없이는 답할 수 없는 비교

## 7.3 질문의 깊이를 한 단계씩 높인다

| 수준 | 질문 예시 |
| --- | --- |
| 관찰 | 무엇이 움직이고 있나요? |
| 비교 | 둘 중 무엇이 더 빠르게 움직이나요? |
| 근거 | 어디를 보고 그렇게 생각했나요? |
| 예상 | 바람이 약해지면 어떻게 될까요? |
| 수정 | 다시 보니 생각을 바꾸고 싶은 부분이 있나요? |

모든 카드가 다섯 단계를 가져야 하는 것은 아니다. 5분 카드라면 관찰과 비교를 기본으로 하고, 근거·예상·수정 중 하나를 선택하는 편이 낫다.

## 7.4 사실과 상상을 구분하되 둘 다 존중한다

아이가 “나뭇잎이 춤을 춰요”라고 말하면 이것은 훌륭한 표현이다. 탐구 질문에서는 상상을 없애지 않고 관찰과 연결한다.

> 춤처럼 보였구나. 어떤 움직임 때문에 그렇게 느꼈어?

## 7.5 탐구 완료의 증거

- 아이가 스스로 대상을 찾았다.
- 차이나 공통점을 하나 표시했다.
- 관찰한 단서와 자신의 생각을 연결했다.
- 다시 보고 생각을 더하거나 바꿨다.
- 보호자의 답을 복창하지 않고 자기 방식으로 표현했다.

# 8장. 창의: 열린 제약 안에서 다르게 보기

## 8.1 자유롭게 하라는 말이 창의성을 만들지는 않는다

완전한 백지는 무엇을 해야 할지 모르게 만들 수 있다. 창의 활동에는 시작할 수 있는 제약과 여러 결과가 가능한 여지가 함께 필요하다.

좋은 열린 제약:

> 움직이는 것 두 개를 찾아 둘만의 팀 이름을 붙여보세요.

대상 수는 제한되어 있지만 이름에는 정답이 없다.

부담이 큰 자유:

> 이 공원에서 완전히 새로운 이야기를 만들어보세요.

## 8.2 창의 행동의 세 단계

1. 모방: 보호자나 카드의 예시를 따라 해본다.
2. 변형: 색, 순서, 이름, 규칙 중 하나를 바꾼다.
3. 생성: 새로운 연결이나 미션을 만든다.

어린 아이에게 모방은 창의성의 반대가 아니라 출발점이다. 예시를 보여준 뒤 그대로 복제했는지 평가하기보다 무엇을 바꾸었는지 본다.

## 8.3 창의성을 관찰하는 방법

- 익숙한 대상을 다른 용도로 상상했다.
- 보호자의 예시에 새로운 요소를 더했다.
- 한 대상에 여러 이름이나 설명을 제안했다.
- 처음 계획이 안 됐을 때 다른 방법을 선택했다.
- 자신이 만든 규칙을 다른 사람에게 설명했다.

## 8.4 창의성을 죽이는 피드백

- “그건 말이 안 돼.”
- “더 예쁘게 그려봐.”
- “정답은 이거야.”
- “다른 친구는 더 많이 했는데?”
- “창의적으로 해봐”라고 말한 뒤 결과를 성인 기준으로 교정하기

대신 이렇게 말한다.

- “그 생각과 연결되는 모습을 하나 가리켜줄래?”
- “처음 생각에서 무엇을 바꿨어?”
- “다른 방법도 하나 있을까?”

## 8.5 카드에 넣기 좋은 창의 장치

- 이름 붙이기
- 두 대상을 한 팀으로 묶기
- 소리나 움직임 흉내 내기
- 익숙한 물건의 다른 용도 상상하기
- 관찰한 패턴으로 간단한 규칙 만들기
- 다른 가족이 풀 단서 만들기

# 9장. 성취: 정답이 아니라 내가 해낸 과정

## 9.1 성취를 아이가 통제할 수 있게 한다

“새 세 종류를 찾아 이름을 정확히 맞히기”는 장소와 사전지식의 영향을 크게 받는다. “서로 다른 새소리 두 개를 구분하고 차이를 표현하기”는 아이가 관찰 행동으로 완료할 수 있다.

원더미션의 완료 조건은 다음과 같은 행동으로 쓴다.

- 내가 발견했다.
- 내가 하나를 골랐다.
- 내가 차이를 찾았다.
- 내가 예상해봤다.
- 내가 다시 해봤다.
- 내가 생각을 바꿨다.
- 내가 다른 사람을 위한 단서를 만들었다.

## 9.2 쉬운 시작과 선택형 도전

카드 한 장에 기본 성공과 선택 도전을 구분한다.

기본:

> 서로 다른 소리 두 개를 찾아보세요.

선택 도전:

> 눈을 감지 말고, 두 소리 중 더 먼 곳에서 들리는 소리를 골라 이유를 말해보세요.

기본만 해도 완료다. 선택 도전은 더 깊게 놀고 싶은 아이에게 제공한다.

## 9.3 과정 중심 피드백

능력을 평가하는 말:

> 정말 똑똑하네. 너는 관찰 천재야.

과정을 되짚는 말:

> 처음에는 나무만 보다가 바닥도 살펴봐서 다른 흔적을 찾았구나.

과정 피드백은 무엇을 했는지 구체적으로 보여준다. 그러나 칭찬 문구만으로 동기 향상을 보장한다고 단정해서는 안 된다. 실제로 다음 카드를 선택하는지, 실패 뒤 다시 시도하는지를 함께 본다.

## 9.4 실패를 설계 정보로 바꾼다

아이가 끝내지 못했을 때 기록한다.

- 어디서 멈췄는가?
- 어떤 도움 뒤 다시 시작했는가?
- 조건을 줄이면 가능했는가?
- 장소에 대상이 충분했는가?
- 문장이 어려웠는가, 활동이 흥미 없었는가?

아이에게는 이렇게 말할 수 있다.

> 오늘은 여기까지 발견했네. 다른 카드로 바꾸거나 다음에 다시 해도 좋아.

## 9.5 외적 보상은 핵심이 아니다

스티커와 배지는 시작을 돕는 장치가 될 수 있지만, 원더핀의 핵심 성취는 발견과 주도권이다. 보상이 없으면 활동이 끝나는 구조가 되지 않도록 다음 행동을 보상 대신 연결한다.

- 내가 고른 다음 카드
- 오늘의 발견 한 문장
- 보호자에게 문제 내기
- 다른 날 같은 카드 다시 해보기

# 10장. 모험: 안전한 불확실성

## 10.1 모험을 위험 행동과 구분한다

캐나다소아과학회는 아이가 알아보고 평가할 수 있는 불확실성인 risk와 아이에게 보이지 않는 위험원인 hazard를 구분한다. 야외놀이에서 모든 불확실성을 제거하는 대신 중대한 부상 위험을 줄이고, 아이가 자신의 한계를 알아가는 기회를 제공하자는 관점이다.

원더핀의 초기 카드에서는 이 원리를 더 보수적으로 적용한다. 모험은 높은 곳 오르기나 빠르게 뛰기가 아니라 다음 경험이다.

- 무엇을 발견할지 모르는 탐색
- 결과를 모른 채 예상하기
- 안전 경계 안에서 방향이나 대상을 선택하기
- 익숙하지 않은 감각이나 관점 시도하기
- 계획이 안 될 때 다른 방법 찾기

## 10.2 원더핀이 제거해야 할 hazard

- 차도, 주차장, 공사구역 접근
- 물가에 가까이 가기
- 시설물 등반이나 높은 곳 오르기
- 눈을 감고 이동하기
- 자연물·생물 채집과 훼손
- 낯선 사람에게 말 걸기
- 얼굴, 차량번호, 집, 학교 촬영
- 정확한 생활 동선이나 위치 공유
- 폭염, 한파, 호우, 미세먼지 상황에서 활동 강행

## 10.3 안전한 모험 장치

- 보호자가 볼 수 있는 경계 안에서 탐색 방향 고르기
- 멀리서 보이는 대상의 정체 예상하기
- 익숙한 길에서 평소 보지 않던 높이·바닥·그림자 보기
- 보호자가 고른 두 안전한 대상 중 하나 조사하기
- 첫 예상과 다른 결과를 발견하고 생각 수정하기
- 중단하거나 돌아오는 선택을 성공으로 인정하기

## 10.4 안전 브리핑은 짧고 행동 중심으로

나쁜 문장:

> 안전사고가 발생하지 않도록 주변 환경에 각별히 주의하세요.

좋은 문장:

> 보호자가 정한 선 안에서 걸어요. 차도·주차장·물가 쪽으로 가지 않아요. 위험하거나 불편하면 바로 멈춰요.

## 10.5 감각과 불안을 고려한다

모험은 모든 아이에게 같은 강도로 제공하지 않는다. 큰 소리, 사람이 많은 공간, 낯선 촉감이 부담인 아이가 있다. 만지기나 가까이 가기를 필수로 만들지 않고 보기, 듣기, 멀리서 고르기 같은 대체 경로를 둔다.

# 11장. 보호자 개입 사다리

보호자의 목표는 아이를 가장 빨리 완료시키는 것이 아니라, 최소한의 도움으로 다시 주도권을 돌려주는 것이다. 단, 안전 위험이 있으면 즉시 개입한다.

## 1단계. 기다리기

질문을 읽은 뒤 5~10초 동안 기다린다. 아이가 주변을 보거나 생각하는 시간을 침묵으로 허용한다.

## 2단계. 되묻기

- 무엇을 먼저 해볼까?
- 어디를 보고 그렇게 생각했어?
- 지금 보이는 것 중 하나를 골라볼까?

새 질문을 여러 개 추가하지 않는다.

## 3단계. 선택 좁히기

- 나무 쪽과 바닥 쪽 중 어디부터 볼까?
- 말로 할까, 손가락으로 가리킬까?

선택지는 2~3개로 제한한다.

## 4단계. 한 단계 시범

보호자가 자신의 생각을 소리 내어 한 번만 보여준다.

> 나는 깃발 끝이 계속 왔다 갔다 해서 바람에 움직인다고 생각했어. 이제 네가 다른 것을 하나 찾아볼래?

시범 뒤 선택을 아이에게 돌린다.

## 5단계. 함께 하기

첫 대상을 함께 찾고 두 번째는 아이가 찾도록 한다. 함께 했다는 이유로 실패 처리하지 않는다. 최고 도움 단계를 기록한다.

## 6단계. 중단 또는 전환

피로, 불안, 반복 좌절, 안전 위험이 보이면 쉬운 카드로 바꾸거나 끝낸다. 중단은 실패가 아니라 자기조절과 안전 선택일 수 있다.

## 도움 기록 예시

| 기록 | 해석 |
| --- | --- |
| 1단계 후 시작 | 문장만으로 시작 가능 |
| 3단계 후 시작 | 탐색 범위나 선택 부담을 줄일 필요 |
| 4단계 시범 후 복창 | 아이 자신의 표현을 추가로 기다릴 필요 |
| 5단계에서도 중단 | 대상 부족, 문장 부담, 흥미 또는 컨디션 점검 |

## 보호자가 피할 말

- “그것도 몰라?”
- “아니, 잘 봐. 정답은 저거야.”
- “빨리 찾아야 다음 카드 하지.”
- “동생도 했는데 왜 못 해?”
- “선생님처럼 정확하게 말해봐.”

## 보호자가 사용할 말

- “천천히 봐도 괜찮아.”
- “네가 본 것을 가리켜줘도 좋아.”
- “어떤 단서가 있었어?”
- “처음 생각과 달라진 게 있어?”
- “여기서 멈출까, 쉬운 카드로 바꿀까?”

# 12장. 원더미션 설계 문법

## 12.1 기본 구조

원더미션의 기본 문법은 다음과 같다.

> 찾기 → 비교하기 → 추론하기 → 표현하기

하지만 네 단계를 한 문장에 넣지 않는다. 앞면에는 시작 행동, 뒷면이나 후속 질문에는 비교·추론·표현을 둔다.

## 12.2 카드 한 장의 여섯 요소

1. 성공 가능성이 높은 야외 장면
2. 아이에게 읽어줄 짧은 문장
3. 찾기 또는 관찰 행동
4. 비교·근거·예상 중 하나
5. 아이가 고를 수 있는 표현 방법
6. 안전상 하지 말아야 할 행동과 중단 조건

## 12.3 초안 작성 순서

### 1. 현상을 고른다

색, 모양, 소리, 움직임, 빛과 그림자, 온도감, 재료, 흔적, 반복과 패턴 중 하나를 고른다.

### 2. 첫 행동을 쓴다

“이해한다”, “배운다”가 아니라 찾다, 가리키다, 고르다, 들어보다, 비교하다처럼 관찰 가능한 동사를 사용한다.

### 3. 비교 기준 하나를 고른다

크기, 거리, 빠르기, 밝기, 거칠기, 반복, 방향, 재료 등 한 가지를 선택한다.

### 4. 생각을 여는 질문 하나를 붙인다

- 어디를 보고 그렇게 생각했어?
- 다음에는 어떻게 될까?
- 둘이 왜 다르게 보일까?
- 다시 보니 바꾸고 싶은 생각이 있어?

### 5. 표현의 대안을 둔다

말하기 외에 가리키기, 고르기, 몸짓, 소리 흉내, 간단한 그림을 허용한다.

### 6. 쉬운 경로와 중단 조건을 쓴다

대상을 하나로 줄이기, 선택지 제시, 함께 첫 대상 찾기, 피로·불안·위험 시 중단을 포함한다.

## 12.4 나쁜 초안을 고치는 예

초안:

> 공원의 생태계를 관찰하고 생물다양성이 왜 중요한지 토론해보세요.

문제:

- 추상어가 많다.
- 현장에서 무엇을 해야 할지 보이지 않는다.
- 사전지식과 긴 언어 표현을 요구한다.
- 5분 안에 완료하기 어렵다.

수정:

> 같은 장소에서 살아 있는 것의 흔적 두 개를 찾아보세요. 둘은 무엇이 다른가요? 말하거나 가리켜도 좋아요.

선택 도전:

> 이 흔적을 남긴 것은 지금 어디에 있을까요? 그렇게 생각한 단서를 하나 골라보세요.

## 12.5 연령별 변형 예

같은 현상: 그림자

4~5세:

> 내 그림자와 나무 그림자를 찾아 가리켜보세요. 어느 쪽이 더 커 보여요?

6~7세:

> 서로 다른 그림자 두 개를 찾고, 가장자리 모양이 어떻게 다른지 말해보세요.

8~9세:

> 그림자 세 개를 골라 밝기나 가장자리로 분류해보세요. 왜 그렇게 나눴는지 실제 모습을 근거로 설명해보세요.

# 13장. 탐구·창의·성취·모험 예시 미션 8개

아래 미션은 완제품이 아니라 설계 원리를 연습하기 위한 초안이다. 실제 장소 성공 가능성과 가족 관찰을 거쳐 수정해야 한다.

## 탐구 1. 바람의 증거

대상: 5~6세

아이에게:

> 바람에 움직이는 것을 하나 찾아보세요. 어디가 움직이는지 가리켜도 좋아요.

한 단계 더:

> 다른 것도 하나 찾아보세요. 무엇이 더 빠르게 움직이나요?

보호자 힌트: 나무 쪽과 깃발·옷 쪽 중 어디부터 볼지 고르게 한다.

관찰 지표: 첫 대상 발견, 두 대상 비교, 움직이는 부분을 가리키거나 말함.

안전: 차도 쪽으로 이동하지 않고 정한 경계 안에서 본다.

## 탐구 2. 흔적 탐정

대상: 7~9세

아이에게:

> 사람, 비, 바람 또는 동물이 남긴 것 같은 흔적 두 개를 찾아보세요.

한 단계 더:

> 누가 또는 무엇이 남겼을지 예상하고, 실제 흔적에서 단서를 하나 골라보세요.

선택 도전: 다시 살펴보고 처음 예상을 바꿔도 좋다.

관찰 지표: 흔적 발견, 원인 예상, 근거 연결, 생각 수정.

안전: 흔적을 만지거나 채집하지 않는다.

## 창의 1. 움직임 별명

대상: 4~6세

아이에게:

> 움직이는 것을 하나 찾아 움직임을 몸으로 흉내 내보세요.

한 단계 더:

> 그 움직임에 재미있는 별명을 붙여볼까요? 두 이름 중 골라도 좋아요.

보호자 힌트: “살랑살랑 춤”과 “왔다 갔다 춤”처럼 두 선택지를 제시한다.

관찰 지표: 움직임 모방, 이름 선택 또는 생성, 보호자 예시 변형.

안전: 제자리에서 작은 동작으로 표현하고 뛰거나 등반하지 않는다.

## 창의 2. 둘만의 팀

대상: 7~9세

아이에게:

> 서로 달라 보이지만 한 팀이 될 수 있는 것 두 개를 고르세요.

한 단계 더:

> 둘을 묶는 규칙과 팀 이름을 만들고, 보호자가 규칙을 맞히게 해보세요.

관찰 지표: 예상 밖 연결, 규칙 생성, 다른 사람 관점 고려, 설명 수정.

안전: 멀리서 보이는 대상을 사용하며 사유지나 제한구역에 접근하지 않는다.

## 성취 1. 첫 발견, 다음 발견

대상: 4~6세

아이에게:

> 둥근 것을 하나 찾아보세요.

완료 선언:

> 첫 발견 완료! 같은 모양을 하나 더 찾을지, 여기서 끝낼지 골라보세요.

보호자 피드백: “바닥부터 살펴봐서 둥근 것을 찾았구나”처럼 사용한 전략을 말한다.

관찰 지표: 1분 안의 시작, 첫 발견, 다음 도전 선택 여부.

## 성취 2. 생각 바꾸기 성공

대상: 7~9세

아이에게:

> 멀리 있는 것 하나를 보고 어떤 재료인지 예상해보세요.

한 단계 더:

> 안전한 범위에서 조금 다른 각도로 보고, 그대로 생각할지 바꿀지 고르세요.

완료 조건: 정답이 아니라 다시 보고 결정을 내리면 완료다.

관찰 지표: 최초 예상, 관찰 방법 변경, 유지 또는 수정 이유.

안전: 보호자가 정한 선을 넘지 않는다.

## 모험 1. 평소와 다른 높이

대상: 5~7세

아이에게:

> 평소 보는 눈높이 말고, 발밑이나 머리 위를 골라 새로운 것을 하나 찾아보세요.

한 단계 더:

> 평소에는 왜 못 봤을까요?

관찰 지표: 탐색 방향 선택, 새로운 대상 발견, 관점 변화 표현.

안전: 눈을 감지 않고 제자리나 안전한 보행 공간에서 본다. 높은 곳에 오르지 않는다.

## 모험 2. 비밀 대상 예측

대상: 7~9세

아이에게:

> 보호자가 안전한 범위 안에서 멀리 보이는 대상 하나를 정합니다. 아이는 색·모양·움직임 단서 세 개 중 하나를 골라 정체를 예상합니다.

한 단계 더:

> 가까이 가지 않고 다른 각도에서 단서를 하나 더 찾아 생각을 확인하거나 바꿔보세요.

관찰 지표: 단서 선택, 불확실성 수용, 예상, 추가 관찰, 수정.

안전: 낯선 사람·차량·주거지를 대상으로 정하지 않는다.

# 14장. 원더미션 검수 루브릭

각 항목을 `0 미충족 / 1 수정 필요 / 2 충족`으로 평가한다. 안전이 0점이면 총점과 관계없이 탈락한다. 16점 이상은 종이 시제품 후보일 뿐, 연령 적합성과 교육효과를 보증하지 않는다.

| 영역 | 0점 | 1점 | 2점 |
| --- | --- | --- | --- |
| 시작 가능성 | 첫 행동이 불명확 | 재설명 후 가능 | 한 번 읽고 1분 내 시작 가능 |
| 인지 부담 | 조건·단계가 과다 | 일부 축소 필요 | 연령 가설에 맞고 단계가 보임 |
| 탐구 | 찾기나 퀴즈로 끝남 | 비교 또는 근거가 약함 | 관찰과 비교·근거가 연결됨 |
| 창의 | 결과가 하나뿐 | 제한적 선택 | 대상·방법·표현 중 선택 가능 |
| 성취 | 정답·속도로 판정 | 과정 기준이 모호 | 아이가 통제할 행동으로 완료 |
| 모험·안전 | hazard 또는 개인정보 위험 | 경계·중단 조건 보완 필요 | 안전한 불확실성과 명확한 경계 |
| 표현 접근성 | 말·쓰기만 허용 | 대안이 하나뿐 | 가리키기·선택·몸짓 등 대안 제공 |
| 보호자 역할 | 답을 대신하게 함 | 힌트 수준이 모호 | 최소 힌트와 중단 조건 명확 |
| 시간·반복 | 7분 초과 또는 장소 의존 | 일부 축소 필요 | 7분 내, 다른 날 반복 가능 |
| 관찰 가능성 | 성공 근거 기록 불가 | 주관적 평가 중심 | 행동·발화·도움 수준 기록 가능 |

## 빠른 탈락 기준

- 채집, 훼손, 위험 이동, 등반, 눈 감고 이동을 요구한다.
- 낯선 사람과의 접촉이나 개인정보 촬영을 요구한다.
- 현장 관찰보다 지식 정답이 중심이다.
- 글쓰기나 읽기를 필수 성공 조건으로 둔다.
- 보호자가 대부분 대신해야 완료된다.
- 대상이 특정 장소에서만 지나치게 드물게 나타난다.

# 16장. 가족 관찰과 전문가 검토

## 16.1 가족 관찰의 목적

5가족 정도의 초기 관찰은 어떤 연령이 더 뛰어난지 비교하거나 교육효과를 증명하는 시험이 아니다. 문장이 이해되는지, 현장에 대상이 있는지, 보호자가 얼마나 개입하는지, 아이가 다시 하고 싶어 하는지를 찾아내는 형성평가다.

## 16.2 관찰자가 기록할 항목

- 가족 식별 코드와 보호자 동의 상태
- 아동 연령대: 4~5세 / 6~7세 / 8~9세
- 장소 유형, 익숙함, 날씨, 소음
- 사용 카드와 시작·완료 여부
- 첫 행동까지 걸린 시간
- 보호자가 질문을 다시 읽은 횟수
- 개입 사다리의 최고 단계
- 아이가 고른 대상·방법·표현
- 관찰 근거가 포함된 말 또는 비언어 표현
- 좌절·피로·이탈 신호
- 재시도, 카드 전환 또는 중단
- 완료 뒤 다음 카드 선택 여부

정확한 생활 동선, 아동 얼굴, 불필요한 개인정보는 수집하지 않는다.

## 16.3 관찰표

| 항목 | 기록 |
| --- | --- |
| 가족 코드 / 동의 | |
| 연령대 | |
| 장소·날씨·소음 | |
| 카드명 | |
| 첫 행동 시간 | |
| 다시 읽기 횟수 | |
| 최고 도움 단계 | |
| 아이가 고른 것 | |

| 재시도·전환·중단 | |
| 다음 카드 선택 | |
| 다음 수정안 | |

## 16.4 보호자에게 물을 질문

- 설명 없이 시작하기 쉬웠나요?
- 어느 문장에서 아이가 멈췄나요?
- 답을 대신 말하고 싶어진 순간은 언제였나요?
- 평소 아이의 놀이와 달랐던 점이 있었나요?
- 같은 카드를 다른 날 다시 사용할 것 같나요? 이유는 무엇인가요?
- 안전하거나 불편하다고 느낀 부분은 무엇인가요?

## 16.5 전문가에게 물을 질문

- 연령별 인지·언어 부담을 과소평가하거나 과대평가한 부분은 무엇인가?
- 보호자 힌트가 아이 주도성을 빼앗는 지점은 어디인가?
- 발달 이정표를 교육 목표나 상품 효과처럼 오용한 문장이 있는가?
- 감각민감성, 장애, 언어 차이가 있는 아이를 배제하는 지점은 무엇인가?
- 모험 장치의 안전 경계와 중단 조건이 충분한가?
- 관찰 지표가 아이의 결과물 완성도보다 과정과 선택을 포착하는가?

## 16.6 결과를 해석하는 규칙

- 한 아이의 반응을 전체 연령 특성으로 일반화하지 않는다.
- 보호자 만족과 아이의 실제 행동을 분리한다.
- “좋아했다”보다 시작 시간, 도움 단계, 재시도, 다음 카드 선택을 본다.
- 실패 카드도 삭제하기 전에 장소 부족, 문장, 단계, 흥미, 피로를 구분한다.
- 다른 날 두 번째 사용을 별도로 기록한다.

# 17장. 최종 체크리스트와 용어

## 미션 초안 전

- [ ] 목표 연령 가설과 장소를 정했다.
- [ ] 현장에서 흔히 만날 수 있는 현상을 골랐다.
- [ ] 안전 경계와 날씨 중단 조건을 정했다.

## 문장 작성

- [ ] 첫 행동이 한 문장 안에 있다.
- [ ] 동시에 기억할 조건이 과하지 않다.
- [ ] 비교 기준이 하나로 보인다.
- [ ] 정답보다 관찰 근거를 묻는다.
- [ ] 말 이외의 표현 방법이 있다.
- [ ] 아이가 하나 이상의 선택을 한다.

## 보호자와 성취

- [ ] 기다리기부터 시작하는 힌트가 있다.
- [ ] 쉬운 완료와 선택 도전이 구분된다.
- [ ] 중단과 전환을 실패로 취급하지 않는다.
- [ ] 과정 중심 피드백 예시가 있다.

## 안전과 개인정보

- [ ] 차도·주차장·물가·공사구역 접근을 유도하지 않는다.
- [ ] 등반·달리기·눈 감고 이동을 요구하지 않는다.
- [ ] 채집·훼손·낯선 사람 접촉을 요구하지 않는다.
- [ ] 얼굴·차량번호·주거지·학교 촬영을 요구하지 않는다.

## 핵심 용어

발달 이정표: 특정 나이에 많은 아이에게 흔히 관찰되는 행동. 진단 도구나 카드 합격선이 아니다.

발달적합실제: 연령의 공통성뿐 아니라 개별 아이의 특성과 문화·언어·능력 맥락을 함께 고려하는 강점·놀이 기반 접근.

안내된 놀이: 아이가 주도권을 유지하면서 성인이 환경, 질문, 제안으로 탐색 목표를 돕는 놀이.

작업기억: 활동에 필요한 정보를 잠시 유지하고 사용하는 능력.

억제: 먼저 떠오른 행동을 잠시 멈추고 상황이나 규칙에 맞게 반응하는 능력.

인지적 유연성: 규칙, 관점 또는 해결 방법을 바꾸는 능력.

형성평가: 효과를 최종 판정하기보다 진행 중 문제를 찾아 설계를 개선하는 관찰.

스캐폴딩: 아이가 혼자 하기 어려운 일을 수행하도록 최소한의 임시 도움을 제공하고, 가능해지면 도움을 줄이는 방식.

risk: 아이가 어느 정도 알아보고 평가할 수 있는 불확실성과 도전.

hazard: 아이에게 잘 보이지 않거나 스스로 판단하기 어려운 중대한 위험원.
