# 아동 발달 기반 원더미션 학습·설계 가이드

- 기준일: 2026-07-17
- 연구 범위: 만 4~9세
- 현재 제품 타깃: 보호자 동반 5~9세
- 상태: 1차 학습 설계, 현장 검증 전

## 1. 이 공부의 목적

이 문서의 목적은 아동 발달 이론을 많이 아는 것이 아니라, 실제 원더미션을 다음 네 질문으로 검수할 수 있게 만드는 것이다.

1. 아이가 설명을 듣고 스스로 시작할 수 있는가?
2. 주변에서 근거를 찾고 비교하며 자기 생각을 표현하는가?
3. 너무 쉽거나 어려울 때 보호자가 답을 대신하지 않고 적절히 도울 수 있는가?
4. 아이가 안전한 범위에서 선택·도전·수정하고 완료감을 느끼는가?

발달 이정표는 많은 아이에게 흔한 행동을 이해하는 참고 자료이며 개별 아이를 진단하거나 카드 적합성을 보증하는 기준이 아니다. 현재 가이드는 공개 근거를 제품 언어로 바꾼 설계 가설이며, 실제 가족 관찰로 검증해야 한다.

## 2. 먼저 배울 여섯 가지

### A. 발달은 영역별로 함께 움직인다

인지, 언어, 사회정서, 신체 발달을 따로 떼어 카드 한 장에 적용하지 않는다. 야외에서 대상을 찾으려면 이동과 주의가 필요하고, 비교 결과를 말하려면 언어가 필요하며, 보호자와 차례를 주고받으려면 자기조절이 필요하다.

설계 적용:

- 한 활동이 동시에 요구하는 부담을 센다: 이동, 기억, 말하기, 그리기, 규칙 전환.
- 말로 설명하기 어려운 아이에게 가리키기·고르기·몸짓·그림의 대체 표현을 둔다.
- 연령만으로 성공을 예측하지 않고 개별 흥미, 언어와 경험 차이를 관찰한다.

### B. 놀이는 선택·탐색·즐거움이 있어야 한다

NAEYC는 놀이를 유아 학습의 중심 실천으로 보고, 아이의 선택과 주도성을 유지하면서 성인이 환경·질문·힌트로 목표를 돕는 안내된 놀이를 강조한다.

설계 적용:

- 찾을 대상, 순서 또는 표현 방식 중 최소 하나를 아이가 고르게 한다.
- 보호자 설명보다 아이가 보는 시간이 더 길게 만든다.
- 정답을 알려주는 해설 대신 “어디를 보고 그렇게 생각했어?”를 기본 후속 질문으로 둔다.

### C. 실행기능은 짧은 규칙과 반복 연습으로 돕는다

실행기능과 자기조절은 작업기억, 억제, 유연한 전환을 포함한다. Harvard 자료는 이 능력이 상호작용과 연습 속에서 발달하며 연령에 맞는 게임과 활동으로 연습할 수 있다고 설명한다.

설계 적용:

- 한 번에 기억할 규칙을 줄이고 `하나 찾기 → 하나 비교하기`처럼 단계가 보이게 한다.
- 규칙 전환은 핵심 재미일 때만 사용하고, 바뀌는 순간을 명확히 말한다.
- 기다리기, 차례 지키기와 멈춤은 짧게 연습하되 실패를 벌점으로 만들지 않는다.

### D. 창의성은 자유방임이 아니라 열린 제약에서 나온다

완전한 백지보다 관찰 대상이나 재료는 제한하고 결과 표현은 열어 둔다. 예를 들어 “움직이는 것 두 개”라는 제약 안에서 이름, 이야기, 몸짓과 그림을 선택하게 한다.

설계 적용:

- 결과가 하나인 질문과 결과가 여러 개인 질문을 구분한다.
- “엉뚱한 답”을 고치는 대신 관찰 근거가 있는지 묻는다.
- 모방 → 변형 → 새로 만들기의 단계를 제공한다.

### E. 성취는 정답보다 유능감과 진전에서 만든다

원더미션의 완료는 지식을 맞히는 것이 아니라 `내가 발견함`, `내 생각을 말함`, `한 번 바꿔 봄`처럼 관찰 가능한 행동으로 정의한다.

설계 적용:

- 성공 조건을 아이가 통제할 수 있는 행동으로 쓴다.
- 어려운 미션에는 더 쉬운 목표와 선택형 힌트를 둔다.
- 칭찬은 능력 평가보다 전략·관찰·수정 행동을 구체적으로 되짚는다.

### F. 모험은 위험 노출이 아니라 안전한 불확실성이다

원더핀의 모험은 낯선 것을 찾아보고, 결과를 모른 채 예상하고, 안전한 범위에서 경로·대상·표현을 선택하는 경험이다. 등반, 차도 접근, 시야 차단, 채집과 낯선 사람 접촉은 모험 장치로 사용하지 않는다.

설계 적용:

- 보호자가 볼 수 있는 활동 경계를 먼저 정한다.
- 아이에게 선택권은 주되 물리적 위험과 개인정보 위험은 성인이 통제한다.
- 중단도 실패가 아닌 선택으로 표현한다.

## 3. 연령대별 관찰·설계 가설

아래 구간은 연구와 시제품 비교를 위한 가설이다. 현재 제품의 공식 난이도 구간 `5~6세 / 7~9세` 변경을 확정하지 않는다.

| 연령 가설 | 흔히 기대할 수 있는 참여 방식 | 카드 설계 시작점 | 어려움 신호 | 피할 패턴 |
| --- | --- | --- | --- | --- |
| 4~5세 | 가장 눈에 띄는 색·모양·움직임 찾기, 가장놀이와 이야기, 짧은 질문 응답 | 한 문장 지시, 한 번에 대상 1~2개, 가리키기·선택·몸짓 허용, 즉시 확인 가능한 완료 | 질문을 반복해도 시작하지 못함, 비교 대상을 잊음, 답 대신 다른 놀이로 전환 | 세 단계 지시, 긴 이유 설명 강요, 글쓰기 필수, 시간 경쟁 |
| 6~7세 | 두 대상의 공통점·차이 말하기, 간단한 규칙 따르기, 예측 후 확인 | 두 단계 활동, 비교 기준 1개, 짧은 이유·예상, 간단한 규칙 전환 | 규칙보다 대상 찾기에만 몰입, 보호자 답을 복창, 실패 후 즉시 포기 | 여러 기준 동시 비교, 정답 유도, 미세한 읽기·쓰기 능력을 성공 조건화 |
| 8~9세 | 기준을 스스로 만들기, 원인 가설·분류 규칙·이야기 확장, 미션 변형 | 아이가 비교 기준이나 방법 선택, 예측-증거-수정, 다른 사람용 미션 만들기 | 설명은 길지만 관찰 근거가 없음, 난이도가 낮아 빠르게 이탈 | 유아적 지시 반복, 답이 명백한 찾기만 제공, 결과물 완성도를 과도하게 평가 |

## 4. 보호자 개입 사다리

보호자는 아래 순서로 가장 적은 도움부터 사용한다. 안전 위험이 있으면 순서를 건너뛰고 즉시 개입한다.

1. **기다리기**: 아이가 주변을 볼 시간을 5~10초 준다.
2. **되묻기**: “무엇을 먼저 해볼까?”, “어디를 보고 그렇게 생각했어?”
3. **선택 좁히기**: “나무 쪽과 바닥 중 어디부터 볼까?”
4. **한 단계 시범**: 보호자가 자기 생각을 소리 내어 한 번 보여주고 다음 선택은 아이에게 돌린다.
5. **함께 하기**: 한 대상을 함께 찾고, 두 번째 대상은 아이가 찾게 한다.
6. **중단·전환하기**: 피로, 불안, 안전 위험 또는 반복 좌절이 보이면 쉬운 카드로 바꾸거나 끝낸다.

기록할 것은 도움의 횟수뿐 아니라 어느 단계에서 아이가 다시 주도권을 가져갔는지다.

## 5. 원더미션 검수 루브릭 초안

각 항목을 `0 미충족 / 1 수정 필요 / 2 충족`으로 평가한다. 안전 항목이 0이면 총점과 무관하게 탈락한다.

| 영역 | 검수 질문 |
| --- | --- |
| 시작 가능성 | 보호자가 한 번 읽은 뒤 1분 안에 첫 행동을 시작할 수 있는가? |
| 인지 부담 | 기억할 대상·규칙·단계가 연령 가설에 맞는가? |
| 탐구 | 찾기에서 끝나지 않고 비교 또는 근거 말하기로 이어지는가? |
| 창의 | 아이가 대상·방법·표현 중 하나 이상을 선택할 수 있는가? |
| 성취 | 정답이 아니라 발견·시도·수정 같은 아이 통제 행동으로 완료되는가? |
| 모험 | 안전한 불확실성과 선택이 있으며 물리·개인정보 위험을 만들지 않는가? |
| 표현 접근성 | 말·가리키기·선택·몸짓·그림 중 대체 방법이 있는가? |
| 보호자 역할 | 답을 대신하지 않는 최소 힌트와 중단 조건이 있는가? |
| 시간·반복 | 7분 안에 끝날 수 있고 다른 장소·날에 다시 할 여지가 있는가? |
| 관찰 가능성 | 아이 행동, 발화, 도움 수준을 기록할 수 있는가? |

WP-011의 후보 40개는 총점 16점 이상을 1차 후보로 삼되, 실제 현장 관찰 전 숫자를 품질 보증으로 사용하지 않는다.

## 6. 네 활동 축을 카드로 바꾸는 법

| 축 | 아이에게 일어날 핵심 행동 | 카드 장치 | 관찰 지표 |
| --- | --- | --- | --- |
| 탐구 | 찾고, 비교하고, 근거를 말한다 | 두 대상, 한 비교 기준, “왜 그렇게 생각했어?” | 스스로 찾음, 차이 언급, 관찰 근거 발화 |
| 창의 | 보이는 것을 다른 방식으로 해석·표현한다 | 열린 이름 짓기, 이야기·몸짓·그림 선택 | 서로 다른 답, 기존 아이디어 변형, 자발적 추가 표현 |
| 성취 | 작은 도전을 끝내고 자신의 전략을 인식한다 | 쉬운 시작, 선택형 힌트, 시도·수정 기록 | 시작, 지속, 힌트 후 재시도, 완료 선언 |
| 모험 | 안전한 범위에서 낯선 것을 선택하고 예상한다 | 탐색 경계, 선택 경로, 비밀 대상·예측 | 선택 주도, 불확실성 수용, 안전 규칙 유지 |

## 8. 현장 검증 설계

### 먼저 성인 전문가에게 확인할 것

- 연령별 인지 부담을 과소·과대평가한 항목은 무엇인가?
- 보호자 힌트가 아이 주도성을 빼앗는 지점은 어디인가?
- 모험 표현이 불안·감각민감성·장애가 있는 아이를 배제하지 않는가?
- 발달 이정표를 교육 목표나 상품 효과처럼 오용한 문장이 있는가?

### 가족 관찰에서 볼 것

- 첫 행동까지 걸린 시간
- 보호자가 질문을 다시 읽은 횟수
- 보호자 개입 사다리의 최고 단계
- 아이가 비교 기준이나 표현 방법을 스스로 고른 여부
- 관찰 근거가 포함된 발화 또는 비언어 표현
- 좌절·피로·이탈 신호와 전환 방식
- 완료 후 같은 카드 또는 다른 카드를 고른 여부

5가족 관찰은 문제를 찾는 형성평가이며 연령별 효과나 시장 전체를 일반화하는 표본이 아니다.

## 10. 아직 답하지 않은 가설

- 현재의 `5~6세 / 7~9세` 두 구간이 실제 카드 난이도 구분에 충분한가?
- 한 카드에 두 난이도를 병기하면 보호자가 적절히 선택하는가, 읽기 부담만 늘어나는가?
- 탐구·창의·성취·모험을 별도 카드 유형으로 나누는 편이 좋은가, 한 미션 안에 섞는 편이 좋은가?
- 스티커·배지 없이도 발견 기록과 다음 카드 선택만으로 반복 성취감이 생기는가?
- 만 4세가 보호자 동반으로 사용할 수 있어도 제품 타깃을 4세로 낮출 사업·안전 근거가 있는가?

이 가설들은 공개 자료만으로 확정하지 않고 WP-011 종이 시제품 관찰에서 비교한다.
