# 원더핀 문서 지도

이 폴더에는 장기적으로 유지할 제품·브랜드 기준과 검토 가능한 기획 산출물을 둔다. 업무 상태와 진행 기록은 `tasks/`, 수치·결정·위험은 `operations/`에서 관리한다.

## 결과물 찾기

만들어진 파일의 내용, 다시 사용하는 상황, 현재 사용 가능 상태와 관련 업무는 [`ARTIFACT_CATALOG.md`](./ARTIFACT_CATALOG.md)에서 찾는다. 결과물·운영 기록·연구·콘텐츠·전달 자료가 저장되는 관리 대상 폴더에 새 파일이나 폴더를 만들면 같은 작업에서 이 카탈로그도 반드시 갱신한다. 등록하지 않은 생성 작업은 완료로 보지 않는다.

## 관리 원칙

- 한 주제에는 현재 기준 문서 하나만 둔다.
- 파일명에 초안 번호를 누적하지 않는다. 대체된 조사·초안은 `archive/`로 이동한다.
- 문서는 목표와 기준을 설명하고, 담당자·목표일·상태·작업 결과는 개별 업무 파일에서 관리한다.
- 확정된 사업 결정은 `operations/DECISIONS.md`, 변동 지표는 `operations/METRICS.md`에 기록한다.
- 장소·가격·운영시간처럼 바뀔 수 있는 정보에는 출처와 확인일을 남긴다.
