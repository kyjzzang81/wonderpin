# 원더핀 결과물 카탈로그

- 최종 갱신: 2026-08-05
- 목적: 만들어진 결과물이 무엇을 담고 있고, 언제 다시 꺼내 쓰며, 현재 사용 가능한 상태인지 빠르게 찾는다.

## 1. 이 문서를 사용하는 방법

1. 아래의 `필요할 때` 열에서 지금 하려는 일을 찾는다.
2. `대표 결과물`을 먼저 연다. 같은 행의 PDF·워크북·원본은 필요할 때만 확인한다.
3. `상태`가 `검토 전`, `현장 검증 전`, `과거 스냅샷`이면 외부 게시·제출·제품 확정에 그대로 사용하지 않는다.
4. 결과물을 수정하거나 새로 만들면 이 표의 내용·상태·관련 업무를 같은 작업에서 갱신한다.

업무 진행 상황은 [`operations/TASKS.md`](../operations/TASKS.md), 개별 완료 조건은 [`tasks/`](../tasks/)에서 확인한다. 이 카탈로그는 업무 보드를 대신하지 않고, 재사용할 파일을 찾는 색인 역할만 한다.

## 2. 상태 표시

| 상태 | 의미 |
| --- | --- |
| 기준 | 현재 의사결정과 제작에 우선 적용하는 문서 |
| 내부 초안 | 방향과 내용을 검토할 수 있으나 외부 확정본은 아님 |
| 현장 검증 전 | 공개 근거를 제품 규칙으로 번역했지만 실제 가족 사용으로 확인하지 않음 |
| 게시 전 초안 | 카피·구성은 준비됐지만 실제 게시와 디자인 확정 전 |
| 사용자 검토안 | 사용자 판단 후 다음 단계로 진행하는 문서 |
| 실행 전 계획 | 실행 순서와 기준은 있으나 모집·결제·운영을 시작하지 않음 |
| 과거 스냅샷 | 재현·기록용이며 현재 게시나 운영에 사용하면 안 됨 |

## 9. 새 파일·폴더 등록 규칙

### 적용 범위

다음 경로 아래에 만드는 **모든 새 파일과 폴더**에 적용한다.

- `assets/` — 로고, 브랜드 원본과 재사용 자산
- `content/` — 인스타그램·Threads 등 채널별 콘텐츠 초안과 게시 준비물
- `docs/` — 장기 유지 기준, 전략, 기획과 학습 문서
- `handoff/` — Canva·개발·디자인 등 다른 도구나 담당자에게 전달하는 파일
- `operations/` — 업무 보드, 결정, 위험, 지표, 주간·기간 보고
- `output/` — 현재 대표 PDF 등 단일 최종 생성 파일
- `outputs/` — 날짜·실행 단위로 묶인 워크북, 미리보기와 검사 결과
- `research/` — 조사 원본, 출처 기록, 검수 데이터와 실험 양식
- `tasks/` — 개별 업무 정의, 상태와 결과 기록
- `wonderpacks/` — 원더팩 브리프, 조사, PDF와 구현 전달 자료

새 파일·폴더 생성과 이 카탈로그 갱신은 하나의 완료 조건이다. 같은 작업에서 카탈로그까지 수정하지 않았다면 생성 작업을 완료로 보고하지 않는다.

위 목록에 없는 새로운 최상위 폴더를 결과물·기록 저장 위치로 만들면, 새 폴더를 만드는 작업에서 이 적용 범위 목록도 함께 갱신한다.

### 기록할 내용

새 폴더를 만들면 다음을 기록한다.

- 폴더 경로와 역할
- 어떤 종류의 결과물을 포함하는지
- 현재 사용 상태와 관련 업무

새 파일을 만들면 다음을 기록한다.

- 파일 경로
- 한 문장으로 설명한 내용
- 다시 꺼내 쓰는 상황
- 현재 상태와 아직 하면 안 되는 사용
- 관련 업무 ID와 기준일
- 원본·파생 파일 관계가 있으면 서로의 링크

### 예외와 변경

- `docs/ARTIFACT_CATALOG.md` 자체를 수정하는 행위는 별도 항목으로 다시 등록하지 않는다.
- `apps/`, `packages/`, `scripts/`, `supabase/`, `.codex/`의 구현·설정 파일은 개별 파일 단위 등록 대상에서 제외한다. 다만 이 경로에서 사람이 재사용하는 보고서·내보내기·디자인 결과물을 만들 경우에는 관리 대상 경로로 옮겨 등록한다.
- 기존 파일의 오탈자·링크만 수정한 경우에는 카탈로그 갱신이 필요하지 않다.
- 기존 파일의 목적, 내용 범위, 상태 또는 대표성이 바뀌면 해당 카탈로그 항목을 갱신한다.
- 결과물을 대체한 새 문서가 생기면 이전 문서는 `archive/`로 옮기고 카탈로그 링크와 상태도 함께 바꾼다.
- 임시 파일이 필요하면 `tmp/`를 사용한다. 일회성 검사 로그, 캐시와 중간 렌더링을 `docs/`, `output/`, `outputs/`에 만들지 않는다.
