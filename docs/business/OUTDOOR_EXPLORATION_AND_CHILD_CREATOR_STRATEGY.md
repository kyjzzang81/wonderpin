# 휴대형 야외 탐험 카드와 아동 미션 창작 전략

- 기준일: 2026-07-17
- 목적: 지금까지 조사한 야외 탐험 상품·창작 서비스를 아카이빙하고 원더핀의 단계별 진입 방향을 정리한다.
- 상태: 카드 수익 검증 우선 방향 확정
- 담당: `business-strategist`

## 1. 전략 결론

원더핀은 두 제품을 동시에 만들지 않는다.

1. **지금:** 휴대형 야외 탐험 카드로 사용성·실제 결제·반복 사용을 검증한다.
2. **다음:** 아이가 종이 템플릿으로 미션을 만들고 다른 가족이 플레이하는 오프라인 확장 키트를 검증한다.
3. **나중:** 반복 창작과 상호 플레이가 확인될 때만 비공개 디지털 제작도구를 검토한다.
4. **가장 나중:** 플랫폼, 공개 UGC, 위치기반 기능과 AR을 검토한다.

따라서 ‘아동 크리에이터 플랫폼’은 현재 제품 정의가 아니라 장기 가설이다. 앱을 만들기 전에 종이에서 창작 가치와 안전한 운영 가능성을 증명한다.

## 2. 첫 제품: 휴대형 야외 탐험 카드

5~9세 아이와 보호자가 산책길·놀이터·공원에서 한 장을 뽑아 약 5분 동안 사용한다.

`찾기 → 둘을 비교하기 → 왜 다른지 상상하기 → 아이의 한 문장 남기기`

### 벤치마크에서 가져올 요소

| 벤치마크 | 적용 아이디어 |
| --- | --- |
| eeBoo의 속성 찾기 | 특정 생물 없이도 가능한 색·소리·촉감·무늬·움직임 사용 |
| Melissa & Doug의 시간 제한 | 한 장 약 5분을 표시해 시작 부담을 낮춤 |
| 실물 카드와 휴대 가방 | 화면을 끄고 야외에 집중하며 반복 산책에 휴대 |
| Wonder Cards의 빈 카드 | 충분히 플레이한 뒤 아이가 미션을 만드는 확장 단계로 연결 |

### 원더핀식 차별화 가설

- 단순 사물 찾기에서 끝나지 않고 비교·추론·표현까지 이어진다.
- 한국의 아파트 산책로·가로수·놀이터·횡단보도·하천공원과 사계절을 반영한다.
- 5~6세는 감각·선택, 7~9세는 비교·원인·규칙 찾기로 난이도를 나눈다.
- 채집·시설물 접촉·차도 접근·낯선 사람 촬영 없이 완료하도록 안전 규칙을 카드에 넣는다.

### 최소 시제품

- 범용 카드 18장, 놀이터·공원·산책길 카드 6장
- 부모용 시작 카드 1장, 안전 카드 1장, 기록지 4장
- 휴대 파우치 또는 밴드
- 소량 30세트

첫 상품의 가격은 확정하지 않는다. 구성과 가격을 최소 2안으로 제시하고 설문 응답이 아니라 실제 결제로 비교한다.

## 3. 국내외 경쟁·벤치마크 아카이브

### 실물 야외 카드

- [Melissa & Doug Indoor/Outdoor Scavenger Hunt](https://www.melissaanddoug.com/products/lets-explore-indooroutdoor-scavenger-hunt-play-set): 공식 기준 4세 이상, 카드 80장, 10분 타이머와 수집 가방, $21.99.
- [eeBoo Outdoor Scavenger Hunt](https://eeboo.com/products/scavenger-hunt-game-outdoors): 공식 기준 3세 이상, 카드 50장, $16.99. 색·크기·재질·촉감·무늬·소리·냄새 등을 찾는다.
- [Hapinest Find & Seek](https://kids.hapinest.com/products/find-seek-scavenger-hunt-card-game): 3세 이상, 카드 35장과 휴대 가방, $9.99.
- [Wonder Cards](https://wondercards.us/products/wonder-cards): 자연 카드 38장과 아이가 만드는 빈 카드 3장을 포함한다.

2026-07-17 공개 검색에서는 `한국 생활권 야외`, `5~9세`, `휴대형 카드`, `찾기·비교·추론`, `반복 사용`을 함께 내세운 국내 대표 상품을 뚜렷하게 확인하지 못했다. 이는 국내 상품이 없다는 뜻이 아니며 스마트스토어·SNS 소규모 판매자와 기관 자체 교구는 추가 조사가 필요하다. 외부 문서에서는 `국내 최초`라고 표현하지 않는다.

### 리얼월드: 사용자 경험과 공개 정보 분리

**사용자 제공 사실:** 대표자는 비어드벤처 운영 당시 리얼월드를 경쟁사로 경험했다. 대표자의 판단으로 리얼월드는 B2B 프로젝트 비중이 높고, 하나의 콘텐츠를 만들 때 스토리텔링과 미션을 함께 설계해야 해 크리에이터 진입장벽이 있다.

**공개 확인 사실:** [리얼월드](https://www.realworld.kr/)는 현실 공간에서 추리·미션을 수행하는 콘텐츠를 제공한다. [기업용 솔루션](https://business.realworld.to/solution)은 NFC·QR과 물리 단서를 디지털 경험으로 연결하고 응답·선택에 따른 미션과 시나리오를 지원한다. 리얼월드 스쿨은 교사 크리에이터와 인터랙티브 교육 콘텐츠 제작을 소개한다.

**확인하지 않은 항목:** 현재 B2B 매출 비중, 고객 수, 콘텐츠별 제작기간과 비용, 크리에이터 유지율은 공개 근거로 확인하지 않았다.

**원더핀 시사점:** 초기에 복잡한 서사형 제작도구나 크리에이터 마켓을 만들지 않는다. 한 장의 검증된 질문 문법으로 제작 부담을 낮추고, 아이의 창작도 빈 화면이 아니라 제한된 오프라인 템플릿에서 시작한다.

### AR도슨트: 기능 참고 사례

**공개 확인 사실:** [AR도슨트](https://www.ardocent.com/)는 공원 산책로 야외 방탈출·생태학습, GPS AR 찾기와 3D 보물 요소를 소개한다.

**확인하지 않은 항목:** 현재 실제 운영 장소 수, 유료 고객, 이용자 반복률, 최근 프로젝트 운영 상태와 아동 직접 제작 기능은 확인하지 않았다.

**원더핀 시사점:** `AR을 배치한다`는 기능 자체는 차별점으로 삼지 않는다. 운영 성과가 불명확한 기술 사례를 시장 검증 근거로 사용하지 않고, 카드와 오프라인 창작에서 고객 행동이 확인된 뒤 표현 수단으로만 재검토한다.

## 4. Gate 기반 제품 순서

### Gate 1. 카드를 실제로 꺼내 쓰는가

- 30세트 제작, 15가족 수령, 10가족 실제 야외 사용
- 5가족이 두 번째 사용
- 70% 이상이 추가 준비 없이 시작하고 7분 안에 한 장 완료
- 아이 발화·그림·현장 메모 등 사용 근거 10건

### Gate 2. 돈을 내고 반복 사용하는가

- 실제 유료 주문 20건
- 구매 후 14일 내 사용률 70%
- 30일 내 3회 이상 사용 가족 30%
- 환불률 10% 이하
- 대표자 인건비 제외 공헌이익이 음수가 아님

Gate 2를 통과하기 전에는 아동 창작 실험을 핵심 일정으로 병행하지 않는다.

### Gate 3. 아이가 오프라인에서 미션을 만들 수 있는가

- 20가족에게 완성 카드와 빈 템플릿 제공
- 12가족 이상에서 아이가 주도해 미션 완성
- 다른 가족의 70%가 설명 없이 이해하고 60%가 완료
- 제작 가족의 30%가 두 번째 미션 제작

보호자가 질문·정답 대부분을 대신 작성한 결과는 아이의 창작으로 계산하지 않는다.

### Gate 4. 디지털이 꼭 필요한가

오프라인 미션의 반복 제작·교환 과정에서 저장, 복제, 비공개 공유, 검수 같은 명확한 불편이 반복될 때만 보호자 계정 기반의 최소 디지털 도구를 검토한다. 기술 가능성이나 AR 선호 설문만으로 개발하지 않는다.

## 5. 아동 창작 단계의 안전 원칙

- 5~9세는 보호자와 공동 제작하고 공개 지도를 기본값으로 사용하지 않는다.
- 정확한 위치, 아이 이름·얼굴·학교·실시간 동선을 공개하지 않는다.
- 초기에는 허가받은 장소 또는 보호자가 확인한 생활권에서 종이카드로 교환한다.
- 미션은 채집·접촉·차도·사유지·위험시설 접근을 요구하지 않는다.
- 디지털 전환 시 만 14세 미만 개인정보와 위치정보에 대한 법정대리인 동의·확인, 검수·신고·삭제 정책을 별도 법률 검토한다.

## 6. 중단 기준

- 무료 사용 가족 중 두 번째 사용이 15가족 기준 3가족 미만이면 카드 구성과 사용 맥락을 재설계한다.
- 유료 주문 20건을 확보해도 30일 내 3회 사용이 20% 미만이면 반복 상품 가설을 축소한다.
- 제품원가·포장·배송·결제 수수료로 공헌이익을 만들기 어려우면 구성·가격·유통 방식을 바꾼다.
- 아이 주도 제작이 20가족 중 8가족 미만이거나 다른 가족의 이해율이 50% 미만이면 창작 제품을 중단한다.
- 위 기준을 통과하지 못하면 플랫폼·AR 개발로 문제를 우회하지 않는다.

## 7. 출처와 확인 한계

- 공개 기능·가격 확인일: 2026-07-17
- 리얼월드의 B2B 중심성과 제작 진입장벽 평가는 대표자의 과거 경쟁 경험이며 현재 사업현황을 확정한 외부 통계가 아니다.
- AR도슨트는 공개 기능만 확인했으며 운영 성과와 현재 활성 상태를 검증하지 않았다.
- 국내 소규모 판매 상품은 전수조사하지 못했다.
- 해외 제품의 국내 배송·환율·재고와 해외 플랫폼의 최신 한국어 지원은 구매·사용 전에 재확인해야 한다.
