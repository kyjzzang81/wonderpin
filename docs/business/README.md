# 원더핀 사업전략 문서

`business-strategist`가 작성하거나 검토한 사업계획, 비즈니스모델, 가격·단위경제성, 시장·경쟁 분석과 시장진입 전략을 보관한다.

사업계획서와 피치덱은 사용자가 제공한 참고 이미지의 `Flow가 살아있는 피치덱 설계 20 Step`을 기본 골자로 사용하며, 상세 기준은 `BUSINESS_PLAN_20_STEP_TEMPLATE.md`를 따른다.

## 문서 원칙

- 기준일과 작성 목적을 적는다.
- 외부 사실과 수치에는 출처를 연결한다.
- 사실, 계산 가정, 해석과 권고안을 구분한다.
- 재무 수치는 계산식과 시나리오를 함께 제공한다.
- 외부 제출본과 내부 검토본을 구분한다.
- 확정된 결정은 `operations/DECISIONS.md`, 위험은 `operations/RISKS.md`, 측정 지표는 `operations/METRICS.md`에도 반영한다.

## 권장 파일명

- `BUSINESS_PLAN_INTERNAL.md`: 내부 기준 사업계획서
- `BUSINESS_PLAN_FOUNDATION.md`: 공용 사업계획서의 확정 사실·가설·자료 수집 순서
- `BUSINESS_MODEL_REVIEW.md`: 비즈니스모델 및 수익구조 검토
- `GO_TO_MARKET_STRATEGY.md`: 초기 시장진입 전략
- `UNIT_ECONOMICS.md`: 가격, 비용과 단위경제성 시나리오
- `COMPETITIVE_LANDSCAPE.md`: 경쟁·대체재 분석
- `COMPETITIVE_LANDSCAPE_IGOGO.md`: 주요 직접 경쟁사 아이고고 심층분석
- `COMPETITIVE_LANDSCAPE_EVERYDAY_INQUIRY.md`: 휴대형 카드의 약 5분 야외 탐구 경쟁·대체재와 검증안
- `OUTDOOR_EXPLORATION_AND_CHILD_CREATOR_STRATEGY.md`: 야외 탐험 카드와 아동 위치기반 미션 창작 플랫폼 전략
- `CARD_VALIDATION_EXECUTION_PLAN.md`: 카드 24장 제작, 무료 사용성, 유료 주문, 반복 사용과 공헌이익 실행계획
