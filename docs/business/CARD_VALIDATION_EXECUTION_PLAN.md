- 기준일: 2026-07-17
- 실행기간: 2026-07-17 ~ 2026-09-28
- 담당: `wonderpin-pm`, `wonderpack-developer`, `business-strategist`
- 상태: 실행 전 계획
- 전제: 인쇄비 집행, 외부 가족 모집·연락, 개인정보 수집과 공개 게시 전 사용자 승인 필요

## 1. 검증 질문

이 계획은 다음 질문에 순서대로 답한다.

1. 24장의 카드가 5~9세 가족에게 안전하고 이해 가능하게 작동하는가?
2. 카드를 받은 가족이 실제 야외에서 꺼내 쓰고 다른 날 다시 사용하는가?
3. 무료 체험이 아니라 판매 가능한 구성에 실제로 결제하는가?
4. 구매 후 14일 안에 사용하고 30일 동안 세 번 이상 사용하는가?
5. 대표자 인건비를 제외한 주문당 공헌이익이 0원 이상인가?

Gate 1은 사용성, Gate 2는 결제·반복 사용·단위경제성을 검증한다. Gate 1을 통과하지 못하면 유료 판매로 넘어가지 않는다.

## 3. Gate 1 — 카드 24장과 30세트

### 3.1 후보 40개 작성

후보는 아래 네 묶음으로 균형 있게 만든다.

- 감각·속성 12개: 색, 모양, 빛, 그림자, 소리, 바람, 촉감
- 비교·규칙 12개: 두 대상의 차이, 반복, 움직임, 원인 상상
- 장면 전용 12개: 놀이터 4개, 공원 4개, 산책길·거리 4개
- 날씨·계절 대체 4개: 비 온 뒤, 더운 날, 추운 날, 흐린 날

각 후보는 `성공 가능성`, `5~6세 이해`, `7~9세 확장`, `5분 완료`, `안전`, `준비물 없음`, `아이 발화 유도`를 각 0~2점으로 평가한다. 안전 항목이 0점인 카드는 총점과 관계없이 제외한다.

### 3.2 24장 선정 구조

- 범용 카드 18장
- 놀이터·공원·산책길 장면 카드 각 2장, 총 6장
- 같은 관찰 대상이 4장 이상 반복되지 않도록 구성
- 5~6세 기본 질문과 7~9세 확장 질문을 한 카드에 함께 표기하는 안을 우선 시험

카드 앞면은 아이에게 읽을 질문과 행동, 뒷면은 보호자용 확장 질문·안전·기록 안내로 제한한다.

### 3.3 30세트 배분

| 용도 | 수량 | 이유 |
| --- | ---: | --- |
| 가족 배포 | 15 | 목표 표본 |
| 교체·재발송 | 3 | 분실·인쇄불량 대응 |
| 내부 반복 시험 | 4 | 연령·장면별 수정 |
| 촬영·판매 페이지 | 2 | 제품 기록과 모집 자료 |
| 보존·비교 | 2 | 버전 전후 비교 |
| 예비 | 4 | 수령 취소·추가 검증 |
| 합계 | 30 |  |

대량 생산 품질을 흉내 내기보다 문장·크기·휴대성·내구성을 검증할 수 있는 최소 사양을 사용한다. 견적은 최소 2곳에서 받고 카드·코팅·재단·파우치·배송을 분리한다.

## 4. 무료 사용성 테스트

### 4.1 모집 퍼널

| 단계 | 목표 | 기준 |
| --- | ---: | --- |
| 신청 또는 추천 유입 | 25팀 이상 | 모집글·지인 추천·인스타그램 신청 |
| 적격·연락 동의 리드 | 20팀 | 5~9세, 2주 내 야외 사용 가능, 연락·기록 동의 |
| 수령 확정 | 18팀 | 일정·수령 방식 재확인 |
| 실제 수령 | 15팀 | 배송 또는 직접 전달 완료 |
| 첫 야외 사용 | 10팀 | 날짜·장소유형·카드·결과 확인 |
| 다른 날 두 번째 사용 | 5팀 | 첫 사용과 다른 날짜의 기록 |

가능하면 5~6세 7팀, 7~9세 8팀을 포함하고 놀이터·공원·산책길 사용이 한 유형에만 몰리지 않게 한다. 기존 지인만으로 구성하면 호의 편향이 커지므로 직접 관계가 약한 가족을 최소 10팀 포함하고 대표자 가족·팀원은 지표에서 제외한다.

### 4.2 참여자에게 안내할 일

- 카드를 받은 뒤 7일 안에 야외에서 최소 한 장 사용
- 첫 사용 뒤 다른 날 한 번 더 사용
- 아이에게 답을 가르치기보다 질문을 읽고 기다리기
- 얼굴·정확한 주소·학교가 나오지 않는 범위에서 짧은 기록 제출
- 좋았던 점보다 꺼내지 않은 이유와 실패한 카드를 솔직하게 기록

시제품을 무상 제공하고 가족이 보관하게 할 수 있지만, 추가 사례비 지급 여부는 모집 전에 사용자 승인을 받는다.

### 4.3 연락 순서

1. 수령 당일: 구성 확인과 안전 안내
2. 수령 3일 후: 사용 여부만 확인하고 미사용 이유 기록
3. 수령 7일 후: 첫 사용 기록 마감
4. 첫 사용 3일 후: 두 번째 사용 알림
5. 수령 14일 후: 두 번째 사용과 종합 인터뷰 마감

후속 연락 횟수와 수신거부 방법을 모집 단계에서 고지한다. 답변이 없는 참여자에게 반복적으로 연락하지 않는다.

## 5. 측정 데이터와 계산식

실행 입력 템플릿은 `research/card-validation/`에 둔다. 저장소에는 익명 ID와 검증 데이터만 기록하고 실제 연락처·배송주소는 넣지 않는다.

### 5.1 가족·사용 이벤트

아동 이름 대신 `F001` 같은 가족 ID를 사용한다.

| 영역 | 필드 |
| --- | --- |
| 모집 | 가족 ID, 연령대, 유입경로, 연락 동의일, 수령 방식 |
| 수령 | 버전, 수령일, 구성 누락·불량 |
| 사용 | 사용일, 장소유형, 날씨, 카드 ID, 시작·완료, 완료시간 |
| 사용성 | 별도 준비 여부, 보호자 설명·개입시간, 이해하기 어려운 문장 |
| 아이 반응 | 실제 발화 또는 그림 여부, 자발 질문, 다시 하고 싶은지 |
| 반복 | 두 번째·세 번째 사용일, 사용 카드, 스스로 카드를 꺼냈는지 |
| 거래 | SKU, 표시가격, 할인, 배송비, 결제일, 취소·환불일과 이유 |
| 비용 | 제품원가, 포장, 배송, 결제수수료, 불량·재발송, 환불비용 |

아동 얼굴, 실명, 정확한 주소·동선은 필수 수집 항목에서 제외한다.

### 5.2 계산식

- 실제 야외 사용률 = 첫 사용 가족 ÷ 수령 가족
- 두 번째 사용률 = 다른 날 두 번째 사용 가족 ÷ 첫 사용 가족
- 7분 내 완료율 = 7분 내 완료 카드 실행 수 ÷ 완료시간이 기록된 실행 수
- 무준비 시작률 = 추가 준비 없이 시작한 가족 ÷ 첫 사용 가족
- 14일 내 사용률 = 수령 후 14일 내 첫 사용 구매 가족 ÷ 환불 제외 구매 가족
- 30일 3회 사용률 = 수령 후 30일 내 3회 이상 사용 구매 가족 ÷ 30일 관찰이 끝난 환불 제외 구매 가족
- 환불률 = 환불 주문 ÷ 결제 완료 주문
- 주문당 변동비 = 제품·포장·결제·배송·불량·재발송·환불 변동비 합계 ÷ 환불 제외 주문
- 주문당 공헌이익 = 고객 실결제액 + 고객 부담 배송비 - 주문당 변동비
- 공헌이익률 = 주문당 공헌이익 ÷ 고객 실결제액

모든 비율은 분모와 분자를 함께 보고한다. 표본 20건의 SKU 차이는 통계적 우열이 아니라 다음 실험 방향을 정하는 탐색 결과로만 사용한다.

## 6. Gate 1 판정

### 진행

- 수령 15팀 이상, 실제 사용 10팀 이상, 두 번째 사용 5팀 이상
- 무준비 시작률과 7분 내 완료율 각각 70% 이상
- 사용 근거 10건 이상
- 안전사고 또는 위험 행동 유도 0건

### 수정 후 재검증

- 실제 사용 7~9팀 또는 두 번째 사용 3~4팀
- 특정 카드의 실패율이 40% 이상
- 문장 이해·휴대·기록 부담이 반복적으로 보고됨

실패 카드 6장 이내를 교체하고 5가족 미니 재시험 후 유료 Gate 진입 여부를 다시 판단한다.

### 중단

- 실제 사용 6팀 이하 또는 두 번째 사용 2팀 이하
- 안전사고 발생 또는 안전상 구조적 결함 발견
- 보호자 설명 없이는 대부분 시작할 수 없음

중단 시 앱 개발로 넘어가지 않고 문제·사용 맥락·제품 형태를 다시 정의한다.

## 7. Gate 2 — 유료 주문 20건

### 7.1 구성·가격 실험

20건으로 가격과 구성을 동시에 나누지 않는다.

- Gate 1에서 카드 내용은 같게 유지하고 슬리브형 8가족, 간단 파우치형 7가족의 휴대·분실·정리 편의를 비교한다.
- 휴대 편의 차이가 명확하지 않으면 저원가 슬리브를 기본으로 선택한다.
- Gate 2에서는 검증 카드 24장, 사용·안전 카드와 기본 포장으로 동일한 한 SKU만 판매한다.
- 가격은 견적 이후 확정하되 계획 가설은 정상가 19,900원, 배송비 3,000원 별도다.
- 첫 10건에는 명시적인 출시가 17,900원, 다음 10건에는 정상가 19,900원을 적용한다.

채널과 메시지는 가능한 한 같게 유지한다. 시간 순서와 고객 구성이 다르므로 두 가격의 차이를 인과적 가격탄력성으로 주장하지 않고, 정상가에서도 결제가 이어지는지 보는 방향성 신호로만 해석한다.

### 7.2 판매 코호트

- 무료 테스트 15가족은 사용성 근거로 활용하되 유료 주문 20건에 포함하지 않는다.
- 무료 테스트 가족이 추가 제품을 실제 결제하면 별도 `테스터 재구매`로 기록한다.
- 신규 구매자 20건을 우선 목표로 하고, 최소 15건은 대표자와 직접 관계가 약한 고객에게서 확보한다.
- 무료 제공, 전액 할인, 대표자 본인 결제는 유료 주문으로 계산하지 않는다.
- `유료 주문`은 결제 완료 후 취소되지 않은 주문으로 정의하고 지인 테스트 결제와 증정은 제외한다.
- 유효 판매 페이지 방문 400회는 통과조건이 아니라 주문 부족 시 유입 부족과 제안·가격 문제를 구분하기 위한 진단 목표다.

### 7.3 판매 후 추적

- 수령 3일: 불량·누락과 첫 사용 여부
- 수령 7일: 미사용 이유와 첫 사용 안내
- 수령 14일: 첫 사용 마감 지표
- 수령 21일: 두 번째·세 번째 사용 확인
- 수령 30일: 3회 사용, 만족·불만, 환불·확장 구매 의향이 아닌 실제 사전예약 선택 확인

## 8. Gate 2 판정

### 진행

- 환불 제외 유료 주문 20건 이상
- 대표자와 직접 관계가 약한 고객의 주문 10건 이상
- 14일 내 사용률 70% 이상
- 30일 내 3회 사용률 30% 이상
- 환불률 10% 이하
- 최소 한 SKU의 대표자 인건비 제외 주문당 공헌이익 0원 이상

### 수정 후 재검증

- 유료 주문 10~19건
- 14일 내 사용률 50~69% 또는 30일 3회 사용률 20~29%
- 제품은 사용되지만 공헌이익이 음수

제안, 카드 수, 파우치, 배송 또는 가격 중 한 가지 주요 변수만 바꿔 10건 추가 코호트로 재검증한다.

### 중단·전환

- 충분한 도달과 구매 제안에도 유료 주문 10건 미만
- 14일 내 사용률 50% 미만 또는 30일 3회 사용률 20% 미만
- 현실적인 판매가에서 공헌이익 0원을 만들 수 없음
- 반복되는 안전·품질 문제 또는 환불률 20% 초과

이 경우 소비자 직접판매형 기본팩을 중단하거나 선물·기관납품·워크숍 부속 교구 등 다른 유통 가설을 별도 검증한다. 플랫폼 개발은 대안으로 간주하지 않는다.

## 9. 예산 가드레일

대표자 출연금 500만 원 전체를 초기 검증에 사용하지 않는다. 아래 금액은 지출 확정값이 아니라 견적 비교와 승인에 사용할 상한 가설이다.

| 단계 | 가드레일 | 포함 항목 |
| --- | ---: | --- |
| Gate 1 | 최대 45만 원 | 교정·시제품 30세트, 기본 포장, 15건 배송, 재인쇄 예비비 |
| Gate 2 | 최대 55만 원 | 판매용 소량 제작, 포장·배송 선지출, 결제수수료, 불량·환불 충당 |
| 합계 | 최대 100만 원 | 실제 매출 회수 전 총 현금지출 상한 |

계획용 Gate 1 예산은 카드 인쇄·재단 18만 원, 포장 9.6만 원, 배송 5.25만 원, 재인쇄 예비비 약 4.1만 원으로 총 37만 원 수준을 가정한다. 실제 발주 전 2~3개 견적을 받아 갱신한다.

각 Gate 집행 전 `수량별 견적`, `세트당 변동비`, `최악의 경우 총 현금유출`, `남는 자기자금`을 한 장으로 보고한다. 광고비, 앱 개발비와 대량 인쇄비는 포함하지 않는다.
