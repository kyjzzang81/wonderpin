# 원더핀 카드 우선 제품 출시 계획

- 기준일: 2026-07-17
- 현재 범위: 휴대형 야외 탐험 카드와 아동 창작 오프라인 확장 키트

## 1. 제품 원칙

원더핀은 웹앱을 먼저 개발하지 않는다. 실물 카드를 가장 작은 완결 제품으로 사용해 가족의 실제 결제와 반복 야외 사용을 검증한다.

첫 제품이 증명할 문장은 다음과 같다.

> 부모가 원더팩을 꺼내 질문 하나를 읽으면 아이가 평범한 야외공간을 5분 동안 다르게 보고, 가족은 이 경험을 반복하기 위해 카드를 구매한다.

## 2. 제품 구성

### 기본 원더팩 시제품

- 범용 탐험 카드 18장
- 놀이터·공원·산책길 장면 카드 6장
- 보호자 사용법 1장
- 야외 안전 원칙 1장
- 아이 발견 기록지 4장
- 휴대 파우치 또는 밴드형 패키지

### 카드 문법

각 카드는 다음 요소만 가진다.

1. 성공 가능성이 높은 야외 장면
2. 아이에게 읽어줄 한 문장
3. 찾기 또는 관찰 행동
4. 비교·이유 질문
5. 아이의 한 문장 또는 선택
6. 안전상 하지 말아야 할 행동

### 연령 난이도

- 5~6세: 색·모양·소리·움직임·감각 선택
- 7~9세: 두 대상 비교·원인 추론·규칙·상상

같은 카드에 연령별 질문을 병기할지 덱을 분리할지는 Gate 1에서 비교한다.

## 3. 개발 전 제작 순서

### Phase 0. 콘텐츠 시제품 — 1주

- 40개 후보 미션 작성
- 안전·장소 성공 가능성·연령 적합성 검토
- 내부 테스트 후 24개로 축소
- 가정용 프린터 또는 소량 인쇄용 시안 제작

### Phase 1. 무료 사용성 테스트 — 3주

- 30세트 소량 제작
- 가족 15팀 배포, 실제 야외 사용 10팀 확보
- 첫 사용과 두 번째 사용을 분리 기록
- 보호자 진행시간, 카드 완료시간, 아이 발화와 휴대 불편 수집
- 실패 카드 삭제·수정

### Phase 2. 유료 파일럿 — 4주

- 검증된 20~30장으로 판매 가능한 소량 제품 제작
- Gate 1에서 포장 구성을 비교하고, Gate 2에서는 동일 상품의 출시가·정상가를 순차적으로 실제 결제로 검증
- 인쇄·포장·결제·배송·불량·환불 원가 기록
- 유료 주문 20건과 실제 사용률 확보
- 주문당 공헌이익 계산

### Phase 3. 아이 창작 확장 키트 — 8주

- 빈 미션 카드와 만들기 템플릿 제공
- 아이가 질문·단서·완료방법을 작성
- 보호자는 안전과 이해 가능성만 확인
- 다른 가족이 설명 없이 플레이
- 제작 아이가 결과를 보고 수정

### Phase 4. 장소·디지털 확장

- 계절팩 또는 서울에너지드림센터 장소팩 테스트
- 보호자 계정·비공개 코드를 사용하는 디지털 제작 프로토타입 검토
- 반복 창작이 확인되기 전 AR은 구현하지 않음

## 4. 판매 검증

### 가격

가격은 5,900원으로 고정하지 않는다. 카드 수, 인쇄 품질, 포장, 배송비와 경쟁상품 가격을 반영해 출시가와 정상가를 순차적으로 실제 결제로 검증한다. 주문 20건에서는 구성과 가격을 동시에 바꾸지 않는다.

가격 질문만으로 지불의사를 판정하지 않는다. 결제 완료, 환불과 실제 사용을 함께 본다.

### 최소 원가표

- 카드 인쇄·코팅
- 사용법·기록지
- 파우치·밴드·박스
- 포장재
- 결제 수수료
- 배송비와 도서산간 추가비
- 불량·재발송·환불 충당
- 주문 포장시간

대표자 콘텐츠 기획 인건비를 제외한 공헌이익과 포함한 손익분기 판매량을 각각 계산한다.

### 초기 판매 채널

- 인스타그램 콘텐츠와 프로필 링크
- 사전 테스트 가족의 추천
- 독립 주문 폼 또는 최소 결제 페이지

스마트스토어·크라우드펀딩·오프라인 위탁은 첫 20건의 직접 판매와 사용 근거 이후 검토한다.

## 5. SNS 역할

인스타그램의 정기 운영과 원더팩 제품 검증을 분리한다.

- `1분 원더미션`: 주 1회 카드뉴스형 간단 야외 미션. 계정 성장과 질문·장면·연령 반응 학습
- `이주의 원더핀`: 주 1회 외부 공개 프로그램 큐레이션. 지역·연령·가격·프로그램 유형 수요 학습
- `원더팩 제작·테스트`: 월 1~2회 비정기. 시제품 모집, 사용 기록과 유료 판매

정기 콘텐츠 CTA는 저장·공유·실행·공식 링크 확인을 사용한다. `테스트 신청`, `구매`, `실제 사용`, `두 번째 사용`은 원더팩 게시물과 제품 Gate에서 측정한다.

## 6. 첫 제품에서 제외

- 가족용 장소·예약 웹앱
- 운영자 가입·프로그램 등록·정원·예약·결제 SaaS
- 내부 운영자 승인 시스템
- 네이티브 앱
- 공개 아동 프로필
- GPS 자유 좌표와 공개 미션
- AR 콘텐츠 제작기
- AI 콘텐츠 자동 생성

기존 `apps/web`, `apps/partner`, `apps/admin` 기술 구조는 장기 플랫폼 가설로 보관하되 카드 검증 기간의 개발 범위로 사용하지 않는다.

## 7. 품질·안전 기준

- 카드 없이도 현장에서 의미가 통하는지 확인한다.
- 생물·자연물 채집이나 훼손을 요구하지 않는다.
- 뛰기, 높은 곳 오르기, 눈을 감고 이동하기를 요구하지 않는다.
- 차도, 주차장, 물가, 공사구역과 사유지 접근을 유도하지 않는다.
- 낯선 사람, 아동 얼굴, 차량번호, 주거지 촬영을 요구하지 않는다.
- 날씨·미세먼지·폭염·한파에 따라 사용을 중단할 기준을 안내한다.

## 8. 검증 데이터

- 가족 식별값과 보호자 동의 상태
- 아동 연령대: 5~6세 / 7~9세
- 사용 장소 유형과 날씨
- 사용 카드와 시작·완료 여부
- 카드 한 장 완료시간
- 아이의 실제 말 또는 보호자 관찰
- 동일 가족의 두 번째·세 번째 사용
- 구매가격, 할인, 배송비, 환불
- 제작·포장·배송 변동비

아동 얼굴과 정확한 생활 동선은 초기 필수 데이터로 수집하지 않는다.

## 9. 다음 제품 판단

- 카드가 팔리지 않으면 플랫폼으로 문제를 해결하려 하지 않는다.
- 카드는 팔리지만 반복 사용되지 않으면 카드 수·선택 방식·보상과 휴대성을 수정한다.
- 반복 사용은 되지만 확장팩 구매가 없으면 단품 또는 기관 유통 모델을 검토한다.
- 아이가 미션 만들기를 반복하지 않으면 아동 크리에이터 플랫폼을 중단한다.
- 아이 창작이 반복되지만 공개 위치 공유가 부담이면 가족·학급·장소 내부 비공개 도구로 제한한다.
