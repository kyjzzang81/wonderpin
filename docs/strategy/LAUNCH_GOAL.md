# 원더핀 런칭 목표

- 기준일: 2026-07-17
- 현재 전략: 휴대형 야외 탐험 카드 우선

## 1. 목표 선언

원더핀은 **2027년 4월 30일까지** 5~9세 가족이 산책길·놀이터·공원에서 반복 사용하는 휴대형 야외 탐험 카드 상품을 출시하고, 실제 유료 구매와 야외 반복 사용을 증명한다.

초기 제품은 운영자 SaaS나 장소 예약 플랫폼이 아니다. 대표자가 직접 기획한 탐험 카드를 소량 제작·판매하여 다음 두 질문에 먼저 답한다.

1. 부모가 아이와 야외에서 바로 쓸 수 있는 탐험 카드에 실제로 돈을 내는가?
2. 아이가 한 번의 찾기 놀이로 끝내지 않고 관찰·비교·추론을 반복하는가?

이 두 질문에 답한 뒤 아이가 직접 미션을 만드는 오프라인 확장 키트를 검증한다. 가족용 앱, AR, 공개 UGC와 운영자 SaaS는 카드·창작 행동의 제품 적합성이 확인된 이후 별도 Gate에서 판단한다.

## 2. 첫 제품의 정의

첫 원더팩은 `휴대형 야외 탐험 카드`다.

- 대상: 보호자 동반 5~9세
- 장소: 산책길, 놀이터, 공원, 거리 등 한국의 일상 야외공간
- 사용시간: 카드 한 장 약 5분
- 준비물: 카드 외 별도 준비물 없음
- 핵심 구조: `찾기 → 비교하기 → 왜 그런지 말하기 → 아이의 한 문장 남기기`
- 안전 원칙: 채집, 차도 접근, 시설물 등반, 낯선 사람·차량·주거지 촬영을 요구하지 않음
- 형식: 휴대 가능한 실물 카드와 최소 기록물

서울에너지드림센터 전용 원더팩은 첫 제품이 아니다. 카드 수익·반복 사용 검증 후 추진할 첫 장소 확장팩 후보로 유지한다.

## 3. 단계별 제품 순서

### 1단계. 원더핀이 만든 탐험 카드

- 완성된 미션을 가족이 야외에서 사용한다.
- 가격, 카드 수, 휴대성, 연령별 난이도와 반복 사용을 검증한다.

### 2단계. 아이가 만드는 오프라인 확장 키트

- 완성 카드 뒤에 빈 미션 카드를 제공한다.
- 아이가 만든 미션을 다른 가족이 설명 없이 플레이하고, 제작 아이가 수정한다.
- 디지털 계정·위치정보 없이 창작과 상호 플레이 자체의 가치를 검증한다.

### 3단계. 관리되는 디지털 창작

- 보호자 계정과 비공개 가족 코드로 미션을 만든다.
- 운영자가 승인한 장소와 템플릿 안에서만 공유한다.
- QR·사진 단서·간단한 위치 인증부터 시작한다.

### 4단계. 플랫폼·AR·운영자 도구

- 앞 단계의 반복 창작·상호 플레이가 확인된 경우에만 AR 배치와 장소별 공개 콘텐츠를 검토한다.
- 프로그램 예약과 운영자 SaaS는 카드 구매 가족, 장소 확장팩과 운영자 수요가 거래 근거로 연결될 때 재개한다.

## 4. 단계별 Gate

### Gate 1. 카드 사용성 검증 — 2026년 8월 14일까지

- 탐험 카드 시제품 24장과 안전·사용법 카드를 완성한다.
- 소량 시제품 30세트를 제작한다.
- 연락 가능하고 개인정보 수집에 동의한 5~9세 가족 리드 20팀을 확보한다.
- 시제품 수령 가족 15팀, 실제 야외 사용 가족 10팀을 확보한다.
- 실제 사용 가족 중 5팀 이상이 서로 다른 날 두 번째로 사용한다.
- 사용 가족의 70% 이상이 별도 준비 없이 시작하고, 70% 이상이 카드 한 장을 7분 안에 완료한다.
- 아이의 실제 말·그림 등 실행 근거 10건 이상을 확보한다.

통과하지 못하면 카드 수, 문장, 난이도, 휴대성과 야외 장면을 수정한다. 앱이나 대량 인쇄로 넘어가지 않는다.

### Gate 2. 유료 수요·단위경제성 검증 — 2026년 9월 28일까지

- 무료 사용의향 조사가 아니라 실제 결제 가능한 파일럿 상품을 판매한다.
- 환불을 제외한 실제 유료 주문 20건 이상을 확보한다.
- 구매 가족의 70% 이상이 14일 안에 한 번 이상 사용한다.
- 구매 가족의 30% 이상이 30일 안에 세 번 이상 사용한다.
- 결제 고객의 환불률을 10% 이하로 유지한다.
- 카드·인쇄·포장·결제·배송을 반영한 주문당 공헌이익을 계산한다.
- 최소 한 가격안에서 대표자 인건비를 제외한 주문당 공헌이익이 0원 이상임을 확인한다.

9월 11일에는 8월 말 구매자의 14일 내 사용률을 중간판정하고, 30일 관찰이 끝나는 9월 28일에 반복 사용과 단위경제성을 최종 판정한다.

기준 미달이면 가격·구성·유통 방식을 수정하거나 휴대형 카드의 독립 유료상품화를 중단한다.

### Gate 3. 아동 창작 오프라인 키트 검증 — 2026년 11월 6일까지

- 카드 사용 경험이 있는 가족 20팀을 대상으로 빈 미션 카드 확장 키트를 테스트한다.
- 아이가 주도해 미션을 완성한 가족 12팀 이상을 확보한다.
- 제작자의 추가 설명 없이 다른 가족이 이해하고 시작한 비율 70% 이상을 달성한다.
- 다른 아이의 미션 완료율 60% 이상을 달성한다.
- 제작 아이의 30% 이상이 2주 안에 두 번째 미션을 만든다.
- 보호자가 대부분 대신 만든 결과는 아이 창작 실적으로 계산하지 않는다.

기준 미달이면 아동 크리에이터 플랫폼을 개발하지 않고 원더핀 제작 카드와 성인·운영자 제작 모델만 검토한다.

### Gate 4. 제품 확장 검증 — 2027년 1월 29일까지

- 기본 카드 1종과 계절·장소 확장팩 중 1종을 유료 판매한다.
- 누적 유료 주문 60건 이상을 확보한다.
- 구매 후 실제 사용 근거가 있는 가족 30팀 이상을 확보한다.
- 기본팩 구매자의 확장팩 구매 또는 유료 사전예약률 15% 이상을 확인한다.
- 서울에너지드림센터 등 관리되는 장소 1곳에서 장소 확장팩을 테스트한다.

### Gate 5. 공개 런칭 — 2027년 4월 30일까지

- 누적 유료 주문 100건 이상
- 실제 야외 사용 근거 가족 50팀 이상
- 30일 내 3회 이상 반복 사용 가족 비율 30% 이상
- 환불률 10% 이하
- 주문당 공헌이익과 월별 현금흐름 측정 가능
- 기본팩 1종과 검증된 확장팩 1종 이상 판매 가능
- 제품 안전, 교환·환불, 개인정보와 고객문의 기준 문서화

## 5. 핵심 고객

- 수도권의 5~9세 자녀를 둔 가족
- 산책·놀이터·공원 방문을 단순 신체활동이 아니라 대화와 탐구로 확장하고 싶은 보호자
- 야외활동 아이디어를 매번 검색하거나 준비하기 어려운 보호자
- 화면 사용을 줄이면서도 짧고 구조화된 활동을 원하는 가족

기관·교육자·운영자는 초기 구매 고객이 아니라 후속 유통·확장팩·프로그램 파트너 후보로 둔다.

## 6. 검증할 핵심 가설

1. 보호자는 한국 생활권 야외에서 바로 쓸 수 있는 휴대형 탐험 카드에 실제 결제한다.
2. `5분`, `별도 준비물 없음`, `화면을 넣고 관찰`이 시작 부담을 줄인다.
3. `찾기 → 비교 → 이유 → 한 문장` 구조가 일반 스캐빈저헌트보다 아이 발화와 반복 사용을 높인다.
4. 5~6세와 7~9세는 같은 장면에서도 질문 난이도를 달리해야 한다.
5. 기본 카드 사용 후 아이가 직접 미션을 만드는 활동에 창작·성취 가치를 느낀다.
6. 기본팩 구매자는 계절·장소 확장팩을 추가 구매한다.

## 7. 초기 비목표

- 가족용 장소·예약 플랫폼 개발
- 운영자용 SaaS 개발
- AR 오브젝트 자유 배치
- 공개 지도와 아동 위치 UGC
- 아동끼리 DM·댓글·팔로우
- 전국 장소 DB
- 대량 생산과 전국 유통 계약
- AI 미션 자동 생성

## 8. 최종 판단 원칙

초기 성공은 팔로워, 카드 아이디어 수나 앱 기능으로 판단하지 않는다.

> 가족이 탐험 카드를 실제로 구매하고 밖에서 반복 사용하며, 아이가 자신의 미션을 만들어 다른 아이에게 건네는가?

이 질문에 결제, 반복 사용과 상호 플레이 데이터로 답할 수 있을 때만 디지털 플랫폼과 운영자 사업으로 확장한다.
