# 아이고고·째깍악어 콘텐츠 모니터링과 반자동 수집 방안

- 기준일: 2026-07-17
- 상태: 사용자 검토안
- 목적: `이주의 원더핀`과 `1분 원더미션`의 소재 탐색 시간을 줄이되 경쟁사 콘텐츠를 복제하지 않고 원더핀의 고객 검증에 연결한다.

## 1. 결론

첫 자동화는 **경쟁사 인스타그램 원문 크롤러**가 아니라 아이고고·째깍악어 **플랫폼 목록과 상세페이지 수집기 + 편집 검수 큐**로 만든다.

- 자동화: 공개 웹의 후보 URL·제목·게시일·연령·지역·가격·예약 상태 수집, 중복 제거, 변경 감지, 만료 표시
- 사람 검수: 운영자 공식 원문 확인, 권리 확인, 5~9세·야외 적합도 판정, 원더핀 카피와 그래픽 제작
- 자동화하지 않음: 인스타그램 로그인 우회, 세션 쿠키 수집, 무한 스크롤 스크레이핑, 경쟁사 이미지·영상·캡션 저장, 자동 게시

2026-07-17 확인 결과 아이고고 공개 웹앱은 인증 없는 공개 목록 API에서 상품별 연령·가격·카테고리·상세 이미지·HTML을 제공한다. 째깍악어 공개 상세페이지는 서버 렌더링 HTML에 해당 지점의 프로그램 목록, 연령·가격·분류와 상세 이미지 정보를 구조화해 포함한다. 따라서 플랫폼 수집은 브라우저 화면 클릭보다 이 공개 응답을 우선 사용하고, 이미지에만 있는 정보는 macOS Vision 한국어 OCR로 보충한다.

전체 실행에서는 아이고고 1,906건과 째깍악어 공개 17개 지점 112건을 수집했다. 째깍악어 112건은 대표 상세 이미지까지 OCR했으며, 원본 이미지는 내부 검수용 로컬 파일로만 보관하고 Git 커밋 대상에서 제외한다.

Meta는 사전 허가 없는 자동 수집을 금지한다. 공식 Instagram API의 Business Discovery는 다른 **프로페셔널 계정**의 공개 메타데이터·미디어와 일부 공개 지표를 조회할 수 있지만, 원더핀 프로페셔널 계정과 Meta 앱·토큰·권한 구성이 필요하다. 따라서 계정 요건을 확인하기 전 비공식 브라우저 크롤러를 운영 대안으로 사용하지 않는다.

## 2. 수집 목적과 경계

### 수집해도 되는 신호

- 프로그램 주제, 계절성, 보호자 고민과 검색 의도
- 릴스·캐러셀·정적 이미지 등 포맷과 훅·CTA의 유형
- 프로그램명, 운영주체, 지역, 연령, 일정, 가격, 공식 예약 링크
- 공개 화면에서 확인되는 좋아요·댓글·조회수와 확인 시각
- 경쟁사·운영자 원문 URL과 내용 변경 여부를 확인할 해시

### 저장·재사용하지 않는 항목

- 경쟁사 사진, 영상, 썸네일, 음원과 캐릭터
- 캡션 문장, 카드뉴스 문구와 디자인 레이아웃
- 아동 얼굴·이름·후기·발화 등 개인정보 또는 동의가 불명확한 UGC
- 공개되지 않은 저장·공유·전환 성과의 추정치
- 로그인, 우회 접속 또는 비공식 API로만 얻을 수 있는 데이터

타사 콘텐츠는 소재 신호이며 원더핀의 발행 자산이 아니다. 원더핀 게시물은 자체 문장과 자체 그래픽으로 다시 만든다.

## 3. 소스별 수집 전략

| 우선순위 | 소스 | 수집 방식 | 자동화 수준 | 주의사항 |
| --- | --- | --- | --- | --- |
| 1 | 운영자·기관 공식 페이지 | HTML·구조화 데이터·사이트맵·RSS 확인 | 높음 | 게시 직전 일정·가격·마감 재확인 |
| 2 | 아이고고 공개 웹·공식 링크허브 | 목록 URL과 최소 사실 수집 | 중간 | robots.txt·이용약관·렌더링 구조 확인 후 저속 수집 |
| 3 | 째깍악어 공개 웹·공식 링크 | 프로그램 후보와 공식 링크 수집 | 중간 | 공개 페이지 범위만 사용 |
| 4 | 아이고고·째깍악어 인스타그램 | 수동 URL 등록 또는 공식 Business Discovery 검토 | 낮음 | 비공식 스크레이핑 금지, 프로페셔널 계정만 가능 |

인스타그램은 주 1회 사람이 최근 게시물 URL을 검수 큐에 넣는 방식으로 시작한다. 원더핀 인스타그램 프로페셔널 계정과 Meta 앱을 마련한 뒤 두 대상이 프로페셔널 계정인지 확인되면 Business Discovery 기술 검증을 별도 수행한다.

## 4. 데이터 구조

경쟁사 원문 보관소와 발행 자산을 분리한다. 원문 미디어를 내려받지 않고 URL, 최소 사실, 해시와 검수 상태만 보관한다.

## 5. 원더핀 편집 규칙

변환 흐름은 다음과 같다.

> 경쟁사 신호 발견 → 운영자 공식 원문 확인 → 5~9세·수도권 가족 프로그램 적합도 판정 → 자체 문장·자체 그래픽 제작 → 사실·권리·브랜드·안전 검수 → 사용자 승인 후 게시

### `이주의 원더핀` 후보 기준

- 공식 원문에서 운영주체, 장소, 연령, 일정, 가격과 예약 상태를 확인할 수 있다.
- 게시 시점에 신청·방문 가능하거나 상태를 정확히 표시할 수 있다.
- 5~9세 가족에게 선택 이유를 설명할 수 있다.
- 원더핀이 운영·판매·검수한 프로그램처럼 보이지 않는다.

### `1분 원더미션` 전환 기준

- 경쟁사의 구체 문구나 활동 순서를 복제하지 않는다.
- 원더핀의 `찾기 → 비교하기 → 추론하기 → 표현하기` 문법으로 독립 제작한다.
- 생활권 야외에서 준비물 없이 약 1~5분 안에 실행 가능하다.
- 채집, 차도 접근, 시설물 등반, 낯선 사람·차량·주거지 촬영을 요구하지 않는다.

## 7. 자동화 설계

### Phase A — 1주 POC

- `research/content-monitoring/sources.json`에 허용 소스와 수집 규칙을 명시한다.
- Node.js 수집기가 공개 페이지의 제목·URL·날짜·최소 사실만 JSONL과 CSV로 저장한다.
- URL 정규화와 `brand + canonical_url`로 중복을 제거한다.
- `source_hash`가 바뀌면 `needs_recheck`로 표시한다.
- 네트워크 오류, 차단 응답, DOM 구조 변화가 생기면 해당 소스를 중단하고 사람이 확인한다.
- 결과는 저장소의 검수 큐에만 기록하고 외부로 게시하지 않는다.

### Phase B — 2주 파일럿

- 주 2회 예약 실행으로 최근 후보를 갱신한다.
- 공식 운영자 URL 탐색과 발행 직전 재확인 목록을 분리한다.
- 20개 표본에서 필드 정확도, 중복률, 만료 탐지율과 건당 검수시간을 측정한다.
- 정확도 90% 미만이거나 사람 검수시간이 줄지 않으면 소스별 파서를 축소한다.

### Phase C — 공식 Instagram API 검증

다음 조건을 모두 만족할 때만 진행한다.

1. 원더핀 Instagram 프로페셔널 계정과 연결된 Meta 앱이 있다.
2. 필요한 로그인·권한·토큰과 앱 검수 요건을 확인했다.
3. 아이고고와 째깍악어 대상 계정이 Business 또는 Creator 계정이다.
4. API가 반환하는 필드와 보존·사용 조건이 이 목적에 맞는다.

POC에서는 `caption`, `media_url`을 저장하지 않고 게시물 URL, 게시 시각, 미디어 유형과 공개 수치만 최소 저장한다. 조건을 충족하지 못하면 수동 URL 등록을 유지한다.

## 8. 품질·중단 기준

### 파일럿 성공 기준

- 최근 후보 20건 표본의 제목·일정·연령·가격 정확도 90% 이상
- 중복률 5% 이하
- 출처와 확인일 누락 0건
- 경쟁사 미디어·캡션 저장 0건
- 수동 후보 탐색·정리 시간이 주당 50% 이상 감소
- 발행 후 일정·마감 정정 0건

### 즉시 중단 조건

- robots.txt 또는 이용약관이 자동 접근을 금지한다.
- 로그인·CAPTCHA·접근제어 우회가 필요하다.
- 403·429가 반복되거나 서비스에 부담을 줄 가능성이 있다.
- 아동 개인정보나 권리 불명 미디어가 저장된다.
- 소스 구조 변경으로 사실 필드가 잘못 매핑된다.

## 9. 필요한 사용자 결정

1. 1차 범위를 `공개 웹 반자동 수집 + 인스타 수동 URL 등록`으로 승인할지
2. 원더핀 Instagram 계정을 프로페셔널 계정으로 운영하고 Meta 앱을 구성할지
3. 파일럿을 저장소의 JSONL·CSV 검수 큐로 시작할지, 이후 관리자 화면으로 확장할지

외부 게시, DM·댓글, 계정 설정 변경과 유료 도구 가입은 별도 사용자 승인 전 실행하지 않는다.
