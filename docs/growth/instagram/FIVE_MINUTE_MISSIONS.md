# 놀이터·공원 5분 원더미션 방향

기준일: 2026-07-14

## 1. 콘텐츠 구분

놀이터와 주변 공원에서 바로 실행할 수 있는 인스타그램 정기 콘텐츠 `5분 원더미션`을 구성한다.

- 장소: 집 주변 놀이터와 공원
- 형식: 인스타그램 게시물·릴스·스토리
- 실행 시간: 5분 이내
- 목적: 채널 참여, 저장·공유 및 고객 니즈 확인
- 구성: 게시물 하나로 완결되는 단일 미션

## 2. 놀이터 미션 소재

- 미는 힘과 당기는 힘 찾아보기
- 흔들리는 것과 고정된 것 비교하기
- 몸의 어느 부분으로 균형을 잡는지 느껴보기
- 놀이터에서 원, 삼각형과 긴 선 찾기
- 놀이기구가 내는 소리를 세 가지 말로 표현하기

## 3. 공원 미션 소재

- 바람이 지나간 흔적 세 가지 찾기
- 가장 밝은 곳과 가장 어두운 곳 비교하기
- 가까운 소리와 먼 소리 하나씩 찾기
- 물이나 비가 지나간 흔적 찾기
- 오늘 공원을 대표하는 계절의 색 정하기

## 4. 발행 원칙

- 준비물을 요구하지 않거나 집에서 쉽게 구할 수 있는 것만 사용한다.
- 5분 안에 시작하고 끝낼 수 있는 질문 하나만 제시한다.
- 부모가 정답을 설명하지 않아도 진행할 수 있게 한다.
- 속도 경쟁, 높은 곳에서 뛰기, 눈을 감고 이동하기 등 위험 행동을 유도하지 않는다.
- 게시물 마지막에 `아이와 해봤나요?`, `아이가 뭐라고 답했나요?`처럼 실제 실행을 확인하는 질문을 둔다.
- 반응이 좋은 미션은 후속편이나 계절별 시리즈로 확장한다.
