# 원더핀 운영 시스템

이 폴더는 AI 에이전트와 사용자가 함께 보는 운영 기준이다.

- `ROADMAP.md`: Gate와 주요 마일스톤
- `TASKS.md`: 전체 업무의 요약 보드
- `DECISIONS.md`: 확정된 의사결정과 근거
- `RISKS.md`: 출시 위험과 대응
- `METRICS.md`: 목표 지표와 실제 값
- `weekly/`: 주간 계획
- `reports/`: 주간 및 Gate 결과 보고서

상세 작업 내용과 산출물 링크는 `tasks/`의 개별 업무 파일에 기록한다. 보드와 개별 파일의 상태가 다르면 개별 파일을 확인하고 즉시 일치시킨다.
