- 영향: 2026-07-17 D-010에 따라 원더팩 Gate 1~2의 핵심은 실물 카드의 야외 사용과 실제 결제로 변경한다. 인스타그램 정기 콘텐츠의 계정 성장·고객학습 지표는 제품 Gate와 별도로 관리한다. 운영자 SaaS 검증은 후속 단계로 유예한다.

## D-005 `이주의 원더핀`은 공개 프로그램 큐레이션으로 운영

- 날짜: 2026-07-16
- 상태: 확정
- 결정: 인스타그램 정기 시리즈 `이주의 원더핀`은 아이고고·째깍악어·마이리얼트립과 기관·운영자 공식 채널에서 발견한 실제 아동 프로그램을 주 1회 큐레이션한다.
- 이유: 가족에게 반복 방문할 정보 가치를 제공하면서 실제로 선택하는 지역·연령·가격·주제와 프로그램 수요를 학습하기 위해서다.
- 영향: 소개 대상은 기관 공식, 공공 연계와 사설 프로그램을 포함할 수 있다. 게시 전 일정·가격·연령·예약 상태를 최신 원문에서 확인하고, 원더핀이 운영·판매·검수한 프로그램처럼 표현하지 않는다. 출처·확인일과 운영주체를 표시하고 이미지·설명문을 무단 복제하지 않는다.

## D-006 브랜드 컬러를 BI 기준 Blue·Yellow·Red로 변경

- 날짜: 2026-07-16
- 상태: 확정
- 결정: 원더핀의 공식 컬러는 Primary `#0167D3`, Secondary `#F3B806`, Third `#EC2127`, Background `#FFFFFF`로 사용한다. 전달받은 BI를 색상과 로고 표현의 최우선 기준으로 둔다.
- 이유: 새 BI의 `wonder` Blue, `p`와 별 Yellow, `in` Red를 제품·문서·운영 산출물에 같은 체계로 반영한다.
- 영향: 이전 Indigo Purple(`#5A3FA3`)과 Soft Pink(`#F28CA6`)는 신규 산출물의 브랜드 컬러로 사용하지 않는다. 기존 운영 산출물은 재생성 또는 수정할 때 새 토큰으로 갱신한다.

## D-007 사업전략 전문 에이전트 운영

## D-008 첫 원더팩은 서울에너지드림센터·5~9세로 확정

- 날짜: 2026-07-17
- 상태: D-010으로 일부 대체
- 결정: 첫 원더팩 장소는 서울에너지드림센터, 핵심 연령은 보호자 동반 5~9세로 확정한다. 초기 원더팩은 대표자가 자체 기획·생산한다.
- 이유: 첫 사업계획서와 현장 검증의 고객·장소 범위를 하나로 고정하고, 대표자의 장소 기반 콘텐츠 기획 경험을 초기 공급 확보에 활용하기 위해서다.
- 영향: 5~9세 기준과 대표자 자체 제작 원칙은 유지한다. 서울에너지드림센터는 첫 판매 제품이 아니라 카드 수익 검증 이후의 첫 장소 확장팩 후보로 이동한다.

## D-009 아이고고를 주요 직접 경쟁사로 분류

- 날짜: 2026-07-17
- 상태: D-010으로 적용 단계 변경
- 결정: 아이고고를 가족용 체험 탐색·예약뿐 아니라 운영자 판매·운영관리 영역의 주요 직접 경쟁사로 분류한다.
- 이유: 공식 가족용 서비스에서 장소 기반 체험, 도슨트, 탐험형 상품, 예약·결제·후기·프로모션을 제공하고 별도 파트너스와 판매자 DX 방향이 확인됐다.
- 영향: 아이고고와 째깍악어는 향후 장소 프로그램·예약 플랫폼·운영자 도구에 진입할 때의 주요 경쟁사다. 휴대형 야외 탐험 카드를 가족에게 직접 판매하는 현재 Gate에서는 실물 야외 카드, 무료 놀이자료와 자연관찰 앱을 더 직접적인 경쟁·대체재로 본다.

## D-010 첫 수익 검증 제품은 휴대형 야외 탐험 카드

- 날짜: 2026-07-17
- 상태: 확정
- 결정: 초기 제품은 5~9세 가족이 산책길·놀이터·공원에서 사용하는 휴대형 야외 탐험 카드 `원더팩`으로 한다. 실제 결제와 반복 사용을 먼저 검증하고, 다음 단계에서 아이가 직접 미션을 만드는 오프라인 확장 키트를 테스트한다. 가족용 플랫폼, 운영자 SaaS, AR과 공개 UGC는 선행 Gate 통과 전 개발하지 않는다.
- 이유: 실물 카드는 대표자가 직접 제작하고 자기자금 범위에서 소량 판매할 수 있어 웹앱보다 빠르게 지불의사와 반복 행동을 확인할 수 있다. 국내 공개 검색에서 한국 생활권·계절과 관찰·추론을 결합한 대표 휴대형 카드 브랜드가 뚜렷하지 않았으며, 해외 제품은 사용성과 가격 벤치마크를 제공한다.
- 영향: 런칭 목표, 제품 계획, 첫 원더팩, Gate, 지표와 업무 우선순위를 카드 우선으로 변경한다. 서울에너지드림센터 자료는 후속 장소 확장팩 후보로 보관한다.

## D-011 디지털 창작·AR보다 아동 오프라인 미션 제작을 먼저 검증

- 날짜: 2026-07-17
- 상태: 확정
- 결정: 완성 카드를 사용한 아이가 빈 카드로 미션을 만들고 다른 가족이 플레이하는 오프라인 확장 키트를 2단계로 둔다. 보호자 계정·비공개 디지털 제작, 관리 장소, AR과 공개 UGC는 순차적으로 검토한다.
- 이유: AR 기술의 흥미와 미션을 직접 설계하는 창작 가치는 다르다. 종이로 창작·상호 플레이가 반복되는지 확인하면 기술 투자 전에 핵심 행동을 검증할 수 있다.
- 영향: 공개 지도, 자유 위치 배치, 아동 계정·사진·동선 수집은 초기 범위에서 제외한다.

## D-019 첫 원더팩 가격·제조원가 기준

- 날짜: 2026-08-05
- 상태: 확정
- 결정: 첫 원더팩의 소비자가격은 VAT 포함 13,900원으로, 원더로그 본체·필기구·스티커·띠지를 합한 제조원가는 세트당 5,000원 이내로 설계한다. 배송비 포함 여부와 실제 판매 수량은 정식 견적과 Gate 2 유료 판매안 승인 시 확정한다.
- 이유: 8,900원에서는 소량 생산과 휴대용 패키지를 함께 유지하기 어려웠다. 13,900원은 핵심 구성과 재사용 가능한 패키지를 보존하면서 결제수수료·배송·불량·출고 비용을 감당할 수 있는 가격 가설이다.
- 영향: WP-011 제작 사양과 WP-012 단위경제성 검증은 제조원가 5,000원을 상한으로 삼는다. 견적이 상한을 넘으면 판매가를 올리기보다 표지·결속·부속품·생산 방식을 먼저 조정하되, 핵심인 24개 미션과 대응 기록 기능은 유지한다.
- 영향: Gate 2 완료일과 WP-012 목표일을 2026-09-28로 변경한다. 일정 도래만으로 통과시키지 않고 성숙한 구매 코호트만 분모에 포함한다.

## D-013 인스타그램 정기 콘텐츠와 원더팩 제품 검증을 분리

- 날짜: 2026-07-17
- 상태: 확정
- 결정: `1분 원더미션`과 `이주의 원더핀`을 각각 주 1회 발행한다. 원더팩 제작·테스트 콘텐츠는 실제 진전이 있을 때 월 1~2회 비정기로 발행한다.
- 이유: 정기 콘텐츠의 계정 성장·고객 학습과 실물 제품의 사용·결제 검증은 서로 다른 목적과 지표를 가진다. 카드 제작 일정에 정기 채널 운영을 종속시키지 않는다.
- 영향: `1분 원더미션`은 도달·저장·실행 반응, `이주의 원더핀`은 저장·링크 행동·프로그램 수요, 원더팩은 신청·사용·결제·반복 사용·공헌이익으로 평가한다. `1분`은 게시물을 이해하고 시작하는 시간이며 실물 카드 한 장의 약 5분 활동과 구분한다.

## D-014 플랫폼 검수 도구는 로컬 내부 도구로만 구현

- 날짜: 2026-07-18
- 상태: 확정
- 결정: 아이고고·째깍악어 수집 데이터의 accept·decline 판정과 재수집 제어를 위해 `apps/admin`에 로컬 파일 기반 검수 도구를 구현한다.
- 이유: 2,018건의 CSV를 직접 검토하기 어렵고, 원본 링크·이미지·요약을 같은 화면에서 확인하며 판정 이력을 다음 수집에 반영해야 한다.
- 영향: 이는 D-010의 가족용 플랫폼·운영자 SaaS 착수와 구분한다. `127.0.0.1`에서만 실행하고 프로덕션 배포, 운영 DB, 로그인과 실제 고객 상태 변경은 포함하지 않는다.

## D-015 Claude–Canva 디자인 입력은 전용 전달 폴더로 격리

- 날짜: 2026-07-18
- 상태: 확정
- 결정: 콘텐츠 원본은 기존 업무 위치에서 관리하고, 문구·사실·사용권 검수가 끝난 디자인 입력만 `handoff/canva/`에 캠페인별 스냅샷으로 둔다. Claude에는 이 폴더만 읽기 범위로 제공한다.
- 이유: 디자인 도구가 불필요한 내부 자료나 미확정 콘텐츠에 접근하지 않게 하면서, Canva 작업에 필요한 브랜드 기준·문구·자산·결과 링크를 한곳에서 전달하기 위해서다.
- 영향: 콘텐츠 담당 에이전트는 디자인 전달 전 템플릿의 상태와 승인 항목을 작성한다. 디자인 과정의 문구 변경은 변경 제안으로 되돌려 검토하며, Canva 작업 완료가 공개 게시 승인을 의미하지 않는다.

## D-016 원더미션 웹 개발 기반은 Next.js App Router와 npm workspaces

- 날짜: 2026-07-18
- 상태: 확정
- 결정: 가족용 `apps/web`과 내부 관리자 `apps/admin`을 각각 Next.js App Router·React·TypeScript 앱으로 구성하고 npm workspaces에서 공통 데이터·UI·설정을 공유한다.
- 이유: 공개 콘텐츠의 서버 렌더링과 관리자 CRUD를 같은 기술 체계에서 운영하면서도 앱별 배포·권한 경계를 유지하고, Supabase 인증·DB·스토리지를 공유하는 데이터 접근 경계를 확보하기 위해서다.
- 영향: 순수 Node 서버와 정적 HTML 실행 경로는 제거한다. 원더미션 운영 CRUD는 D-017의 Supabase 연동이 끝나기 전 완료로 보지 않으며 관리자 앱을 외부 배포하지 않는다.

## D-017 원더미션은 Supabase 단일 저장소를 사용

- 날짜: 2026-07-18
- 상태: 확정
- 결정: 원더미션 메타데이터와 WYSIWYG HTML은 Supabase Database, 썸네일과 본문 이미지는 Supabase Storage에 저장한다. JSON 파일과 로컬 업로드 디렉터리를 임시 CRUD 저장소로 사용하지 않는다.
- 이유: 임시 파일 저장과 운영 저장이 병존하면 데이터 이관, 권한, 이미지 경로와 완료 판정이 모호해진다. 처음부터 운영 목표 저장소와 권한 경계를 하나로 고정한다.
- 영향: `WP-016`은 Next.js UI 기반까지만 검토하며 CRUD 완료 조건은 `WP-017`에서 Supabase 프로젝트·스키마·Storage·Auth·RLS를 연결한 뒤 판정한다. 연동 전 화면과 API를 운영에 사용하거나 배포하지 않는다.

## D-018 첫 원더팩은 24개 미션과 기록이 결합된 탈착식 원더로그로 구성

- 날짜: 2026-08-04
- 수정일: 2026-08-05
- 상태: 확정
- 결정: 첫 원더팩은 별도 카드와 패키지 상자를 없애고, `발견 탐정·비교 대결·생각 실험·상상 발명` 각 6개씩 총 24개 미션과 대응 기록 템플릿을 탈착식 링 원더로그에 직접 인쇄한다. 사용법과 안전 원칙은 앞부분 고정 내지로 넣는다. 짧은 색연필과 원더핀 굿즈 스티커는 보조 구성으로 두고 외부 포장은 종이 띠지만 사용한다.
- 이유: 미션 수행과 기록을 한 물건 안에서 연속시키면 분실과 포장 원가를 줄이고, 사용 후에는 24번의 발견이 축적된 아이 고유의 결과물이 남는다. 탈착식 구조는 오늘 사용할 미션만 고르고 순서를 바꾸거나 후속 리필을 추가할 수 있게 한다.
- 영향: 별도 24장 카드, 사용법·안전 카드와 패키지 상자 가정은 과거안으로 전환한다. WP-011은 미션·기록 한 펼침의 정보 위계, 링 장치, 표지 닫힘, 색연필 수납, 스티커, 5,000원 제조원가 상한을 함께 검증한다. `DAY 1~24`처럼 연속 수행을 강요하지 않고 `24개의 원더미션`으로 표현한다.
