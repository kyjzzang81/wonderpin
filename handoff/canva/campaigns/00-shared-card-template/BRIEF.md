# 디자인 브리프

- 캠페인: 인스타그램 공통 카드뉴스 템플릿
- 목적: 두 정기 시리즈의 일관된 인지도와 모바일 가독성 확보
- 대상: 수도권 5~9세 자녀 보호자
- 채널: Instagram Feed Carousel
- 기본 규격: `1080 × 1350px`, 4:5
- 산출물: `1분 원더미션`, `이주의 원더핀`, 연구 기반 보호자 콘텐츠의 Canva 템플릿

## 공통 방향

- 흰 배경과 짙은 중립색 본문을 기본으로 한다.
- Wonder Blue `#0167D3`를 제목·번호·핵심 구조에 사용한다.
- Wonder Yellow `#F3B806`는 발견·실천 배지에, Wonder Red `#EC2127`는 짧은 대비어에만 쓴다.
- 한 장에 핵심 메시지는 하나만 둔다.
- 하단에는 시리즈, 소요시간, 출처 또는 주의 문구를 배치할 수 있는 공통 영역을 둔다.
- 로고 비율과 색상을 바꾸지 않는다.

## 필요한 컴포넌트

1. 시리즈 표지와 슬라이드 번호
2. 큰 질문형 제목
3. 2~4개 항목 리스트
4. 전후 질문 비교 블록
5. Yellow 실천 배지
6. 출처·확인일·예약 상태 하단 바
7. CTA 마지막 장
8. 안전 안내와 정보 변동 안내

## 기본 스타일 방향 (2026-07-18 확정)

B안: 권리 확인된 사진과 도형을 함께 사용하는 사진 중심 스타일로 결정.

주의: 사진 중심 스타일이라도 캠페인별로 사용 승인된 사진이 없으면 해당 캠페인은 자체 도형·선·아이콘으로 대체한다. 연구 기반 콘텐츠와 프로그램 큐레이션처럼 사진 권리가 없는 경우 자체 그래픽만 사용하는 원칙은 유지한다.
